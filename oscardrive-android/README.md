# Oscar Drive — تطبيق أندرويد واحد لشاشة العربية

فكرة المالك (٢٠٢٦-١١-٠٥): بدل ٧ تطبيقات، تطبيق واحد بالعرض (Landscape) لشاشة التابلوه الأندرويد
(زى CT-850 فى الفيرنا) — من غير إنترنت ولا حساب ولا سيرفر، وكله SQLite على الشاشة.
والـAPK بيتحمّل من «من أعمالنا»: `oscardevs.com/apps/oscar-drive/download`.

محرّك السرعة منقول من «مراقب السرعة» (`speedguard-android/SpeedLogic.kt`) زى ما هو — متجرّب على
الطريق. والتطبيقين منفصلين: مراقب السرعة فاضل زى ما هو (فيه وضع الشركات/الأساطيل).

## حدود متعمّدة
- **كاميرا الرجوع**: التطبيق مابيلمسهاش — الشاشة بتفتحها مع المارشدير فوق أى تطبيق. وقياس مسافة الركن
  محتاج حساسات، الكاميرا لوحدها ماتقيسش.
- **مفيش إذن SMS ولا كاميرا ولا ميكروفون**: الطوارئ بتفتح برنامج الرسايل والسواق بيدوس إرسال، والأوامر
  الصوتية بتروح لبرنامج التعرّف على الكلام اللى على الشاشة (لو مش موجود: الأزرار).
- **مفيش بيانات محرّك (OBD-II)** لسه — محتاجة جهاز Bluetooth، مرحلة جاية.
- نسخة `debug` بمفتاح GitHub المؤقّت: التحديث محتاج مسح القديمة (وبياناتها). لما نثبّت مفتاح توقيع
  كسرّ فى GitHub التحديث هيبقى فوق القديمة.

## البناء والاختبار
بيتبنى على GitHub (`.github/workflows/oscardrive-apk.yml`) مع أى push بيغيّر `oscardrive-android/`:
اختبارات `logic-test` الأول (الرحلة · ذاكرة الطريق · الاستراحة · الصيانة/البنزين · الشروق/الغروب ·
الأوامر الصوتية) وبعدين `assembleDebug`، وبينشر pre-release على التاج `oscardrive-latest`.
(حاوية التطوير قافلة `dl.google.com` فمابتبنيش APK — بس المنطق بيتختبر فيها، والكود كله بيتعمل له
compile على `org.robolectric:android-all` كفحص أنواع.) الحارس: `node scripts/check-oscardrive.js`.

## الملفات
| الملف | الدور |
|---|---|
| `logic/*.kt` | المنطق الصافى (متختبر على الكمبيوتر): `TripLogic` · `RoadMemory` · `Wellness` · `CarCare`/`Fuel` · `SunTimes` · `VoiceCommands` · `Geo` |
| `SpeedLogic.kt` | محرّك السرعة والتنبيه (من مراقب السرعة) |

| `Db.kt` | SQLite: رحلات · مطبات · أماكن · ركنات · صيانة · تفويلات · تجاوزات |
| `MainActivity.kt` + `Ui.kt` | الواجهة (من غير XML) |
| `Speaker.kt` · `Prefs.kt` · `BootReceiver.kt` | الصوت · الإعدادات · يشتغل مع العربية |

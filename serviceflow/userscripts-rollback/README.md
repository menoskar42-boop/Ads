# نسخ قديمة من سكربتات التمبر منكى — للرجوع لو النسخة الجديدة عملت مشكلة

المالك طلب (٢٠٢٦-١١-٠٣): «احتفظ بيها علشان نرجعلها لو حصلت مشكلة فى الأكواد الجديدة».

| النسخة القديمة | اتستبدلت بـ | ليه |
|---|---|---|
| `provisioning-portal-1.8.0.user.js` | `../provisioning-portal.user.js` 1.9.0 | غيّر البورت: بعد Submit بيتأكد إن الطلب اتلقى فى Search For My Requests ويبعت النتيجة |
| `dzs-expresse-v10-10.36.0.user.js` | `../dzs-expresse-v10.user.js` 10.37.0 | «بدون Real» مابقاش بيقرا المسافة، و«تحديث المسافة» (sf_mode=loop) مهمة لوحدها |

**الرجوع:** افتح Tampermonkey ← السكربت ← امسح الكود والزق النسخة القديمة ← Save.
السيرفر بيقبل الاتنين: النسخ القديمة نتايجها بتظهر زى الأول.

**إلغاء الإسناد** شغّال جوّه السكربت المدموج «TE FCC + WFM + OSS + SubInfo» (سكربت wfm-dispatcher-reassign المنفصل اتشال من Tampermonkey من v3.5.0)، وده بيبلّغ كل وقوف من 3.6.7 عن طريق cancel-ingest — فالنتيجة («اتعمل» أو السبب) بقت بتتصنّف فى السيرفر (`cancelResultOf`) من غير أى تعديل فى السكربت.

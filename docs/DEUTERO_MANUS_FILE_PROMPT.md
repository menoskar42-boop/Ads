# برومبتين: ملف الأسفار القانونية التانية اللى عمله مانوس ← GitHub

> المالك ٢٠٢٦-١٠-٣٠: مانوس عمل ملف JSON بنص الأسفار القانونية التانية
> (https://manus.im/share/file/f5dac43c-69af-44fa-a674-2a159eafbd8c) والمالك مش عارف ينزّله مباشرة، وبيئة كلود
> مقفول فيها manus.im. «اعملى برومبت يحمله على GitHub و يبعت اللينك او يعمل الملف فى صيغه اخرى».
> **البرومبت ١ لمانوس** (نفس المحادثة اللى عمل فيها الملف): يعيد حفظ **نفس البيانات** بصيغ تتنزّل (zip وtxt) ويكتب
> ملخّص بمصدر النص وعدد الإصحاحات والآيات. **البرومبت ٢ لكلود إكستنشن**: ياخد الملف اللى نزل ويرفعه على GitHub
> فى فرع لوحده `deutero-sttakla-import` ويبعت اللينك. مانوس مابياخدش أى توكن GitHub — الرفع من متصفح المالك.
> كلود بعدها بيقارن الملف بنفس النص اللى جروب مار مرقس بيقراه قبل ما القطمارس يعتمد عليه
> (`docs/DEUTERO_STTAKLA_IMPORT_PROMPT.md` هو البديل لو الملف ماعداش الفحص).

## البرومبت ١ — لمانوس

```
الملف اللى عملته (ملف JSON بنص الأسفار القانونية التانية) مش بيتنزّل عندى من صفحة المشاركة.
عايزك تعيد حفظ نفس البيانات بالظبط — من غير أى تعديل فى النص ولا الترقيم ولا إعادة كتابة —
فى الصيغ دى، وتدينى لينك تنزيل مباشر لكل واحد:

1) deutero.zip — جوّاه نفس ملف الـJSON زى ما هو.
2) deutero.txt — نفس محتوى الـJSON بالحرف، بس امتداده txt.

لو الملف كبير على لينك واحد، قسّمه ملف لكل سفر بنفس الشكل (deutero-<اسم السفر>.txt).

وبعدها اكتبلى ملخّص قصير:
- مصدر النص بالظبط: اسم الترجمة، واللينك اللى جبت منه كل سفر.
- لكل سفر: اسمه، عدد الإصحاحات، عدد الآيات.
- هل فيه إصحاح ناقص، أو آيات أرقامها مش متتالية (مثلاً ١، ٢، ٤)؟ اكتبها بالاسم.
- أول آية فى طوبيا الإصحاح ٢ بالحرف.

ممنوع: تلخّص النص، أو تكمّل آية ناقصة من عندك، أو تترجم، أو تصحّح كلمة. لو حاجة ناقصة سيبها ناقصة
وقولّى عليها.
```

## البرومبت ٢ — لكلود إكستنشن (بعد ما الملف ينزل فى Downloads)

```
مهمتك ترفع ملف واحد على GitHub فى فرع جديد وتبعتلى اللينك. مفيش أى حاجة تانية.

خطوط حمرا:
- ارفع الملف ده بس. ماتعدّلش ولا تمسح أى ملف تانى فى المستودع.
- ماتعملش Pull Request، وماتغيّرش أى إعداد، وماتلمسش فرع claude/build-oscardevs-ads-mvp-8krfN
  نفسه (الرفع بيروح لفرع جديد).

الخطوات:
1) لو الملف لسه مانزلش: افتح صفحة المشاركة بتاعة مانوس اللى المالك هيديهالك ودوس زرار التنزيل
   (Download). الملف ممكن يكون deutero.zip أو deutero.txt أو ملف JSON — أى واحد منهم ينفع.
2) افتح:
   https://github.com/menoskar42-boop/Ads/upload/claude/build-oscardevs-ads-mvp-8krfN/mybible/data/deutero
3) ارفع الملف من Downloads. لو مش قادر تختار ملف من الجهاز: وقّف وقولّى «اسحب الملف بإيدك على
   الصفحة»، وكمّل بعد ما المالك يسحبه.
4) رسالة الـcommit: deutero: Manus deuterocanon text file (data only)
5) اختار «Create a new branch for this commit» واسم الفرع بالظبط: deutero-sttakla-import
   (لو قالك الفرع موجود: اكتب deutero-manus-import بدله).
6) دوس «Propose changes». الصفحة اللى بعدها (Open a pull request) ماتعملش فيها حاجة.
7) افتح الملف اللى اترفع فى الفرع وابعتلى لينكه، واسم الفرع، وحجم الملف.
```

## 1) تعدّد العملات (Phase 33)
1. **التاجر:** لوحة التاجر → **«تعدّد العملات»** → أضف عملة: الكود `USD`، الرمز `$`،
   المعدّل `0.02` (يعني 1 جنيه = 0.02 دولار) → احفظ. لازم تظهر في القائمة.
2. **المتجر:** افتح `delta.oscardevs.com` → لازم يظهر **محوّل عملة** فوق يمين/شمال قائمة المنتجات.
3. بدّل لـ`USD` → **كل الأسعار في كروت المنتجات تتحوّل فوري** (السعر × 0.02) والرمز يبقى `$`.
   - **راجع يدوياً:** منتج بـ100 جنيه لازم يبقى 2.00 $.
4. اعمل Refresh → لازم يفتكر آخر عملة اخترتها.
5. **السويتش:** من «مميزات المتجر» اقفل «تعدّد العملات» → المحوّل يختفي. رجّعه.

## 2) صفحات الهبوط (Phase 30)
1. **التاجر:** لوحة التاجر → **«صفحات هبوط»** → لازم تلاقي لكل منتج **رابط هبوط** + زر «نسخ» + «معاينة».
2. اضغط «معاينة» لأي منتج → تفتح **صفحة هبوط** فيها: صورة كبيرة، اسم المنتج، السعر (والخصم لو فيه)،
   شارات ثقة (شحن/دفع عند الاستلام/استبدال)، وزر كبير **«اطلب الآن — الدفع عند الاستلام»**.
3. اضغط «اطلب الآن» → لازم يوديك على **صفحة الدفع مباشرة** (Buy now) بالمنتج ده.
4. **SEO:** في كود صفحة الهبوط لازم يكون فيه `noindex` و`canonical` بيشاور على صفحة المنتج
   العادية (مش نفس الرابط) — عشان مفيش محتوى مكرر.
5. لو للمتجر رقم واتساب → لازم يظهر كمان زر **«اطلب على واتساب»**.

## 3) الاشتراكات المتكررة (Phase 32)
1. **التاجر:** عدّل أي منتج → في الفورم فعّل **«اتاحة الاشتراك المتكرر»** + حط «كل 30 يوم» + «خصم 10%» → احفظ.
2. **العميل (مسجّل دخول):** افتح صفحة المنتج ده → لازم يظهر زر **🔁 «اشترك — يوصلك كل 30 يوم (وفّر 10%)»**.
3. اضغطه → لازم يودّيك على **`/customer/subscriptions`** برسالة نجاح، والاشتراك يظهر بحالة نشط +
   تاريخ التجديد القادم + السعر بعد الخصم.
4. **التاجر:** لوحة التاجر → **«الاشتراكات»** → لازم تلاقي اشتراك العميل ده باسمه والمنتج وتاريخ التجديد.
5. **العميل:** ارجع `/customer/subscriptions` → اضغط **«إلغاء»** → الحالة تبقى «ملغي».
6. **(اختياري للمالك)** لتجربة التجديد التلقائي فوراً: نفّذ يدوياً
   `https://oscardevs.com/api/subscriptions/run-daily?key=<PUSH_CRON_SECRET>` →
   لازم يرجّع JSON فيه `ordered`، ويتعمل طلب جديد للاشتراكات المستحقّة (لو تاريخها النهاردة).

## 4) إعادة اختبار سريعة (اللي اتصلح قبل كده)
- **شات المطاعم** (`orders.oscardevs.com`): اطلب برجر + مشروب → قول «شيل المشروب» → **لازم يتشال فعلاً من السلة**.
- **الصيدلية** (`pharmacy.oscardevs.com`): زر «أضف» يتنقر بالماوس عادي ويضيف للسلة.
- **صفحة الدفع** (متجر فيه شحن): لازم فيها **ملخص طلب + إجمالي** بيتحدّث لما تغيّر المحافظة.
- **العيادة:** فاتورة باختيار طبيب → ادفعها → **حسابات الأطباء** في `/clinic/finance` لازم تظهر نصيب الطبيب.

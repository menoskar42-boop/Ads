# 🎨 برومبت Claude Design — صفحة هبوط جيم/كمال أجسام احترافية

> انسخ الكل لكلود ديسين (أو أي أداة تصميم AI). الهدف: صفحة جيم **عصرية، جذابة،
> مليانة صور لاعبين كمال أجسام، ومتبانش إنها معمولة بالـAI**. RTL عربي.

---

انت مصمم واجهات محترف متخصص في مواقع اللياقة والجيم. صمّم **صفحة هبوط واحدة (single-page)
لجيم كمال أجسام ولياقة** بجودة وكالة تصميم حقيقية — مش قالب AI عام. المطلوب:

## الهوية البصرية
- **مود رياضي جريء وداكن:** خلفيات سوداء/رمادي فحمي (#0a0a0a → #171717) مع لون تمييز
  واحد قوي (اختَر: **أصفر نيون #E4FF1A** أو **برتقالي ناري #FF5A1F** أو **أحمر #E11D2A**) —
  استخدمه بقلّة للأزرار والأرقام المهمة بس.
- خط عربي عريض قوي للعناوين (زي **Cairo / Tajawal Black 800–900**) وخط أنظف للنص.
- إحساس «قوة وطاقة»: تباين عالي، مساحات سوداء واسعة، صور كبيرة full-bleed.
- **مهم — ميبانش AI:** استخدم صور فوتوغرافية حقيقية للاعبين (مش رسوم/3D لامعة)،
  زوايا تصوير متنوعة، تفاصيل واقعية (عرق، إضاءة استوديو/جيم حقيقي)، layout غير متماثل
  (asymmetric)، وتفاصيل ماركة (شعار الجيم، أسماء مدرّبين حقيقية بالعربي).

## الصور (كلها لاعبين كمال أجسام/لياقة حقيقيين)
- Hero: صورة لاعب كمال أجسام ضخم في وضع استعداد/رفع أثقال، إضاءة درامية جانبية،
  والنص فوقها بتدرّج أسود من تحت.
- قسم الكلاسات/التدريب: صور أثناء التمرين (سكوات، ديدليفت، بوكس، كارديو).
- المدرّبون: بورتريهات احترافية لكل مدرّب.
- المعرض (Gallery): 6–9 صور من داخل الجيم (أجهزة، منطقة أوزان حرة، بوكسينج).
- Before/After لأعضاء (تحفيزي).

## الأقسام (بالترتيب)
1. **Navbar** شفّاف يثبت عند التمرير — شعار الجيم + روابط (الباقات، الكلاسات،
   المدرّبون، اتصل) + زر بارز **«اشترك الآن»**.
2. **Hero** ملء الشاشة: عنوان قوي («ابنِ جسمك. اكسر حدودك.») + جملة فرعية + زرّين
   («اشترك الآن» + «احجز جولة مجانية») + شارات ثقة صغيرة (عدد الأعضاء، سنين الخبرة).
3. **شريط أرقام** (Stats): +500 عضو · 15 مدرّب معتمد · 40 كلاس أسبوعي · مفتوح 24/7.
4. **مميزاتنا** (Cards بأيقونات): أجهزة حديثة · مدرّبون معتمدون · أوزان حرة · كارديو ·
   حجز أونلاين · متابعة تقدّم.
5. **باقات الاشتراك** (Pricing): 3 كروت (شهري / 3 شهور / سنوي) — الأوسط «الأكثر
   طلباً» مميّز باللون. سعر واضح + مميزات كل باقة + زر «اشترك».
6. **جدول الكلاسات** (Schedule): جدول أسبوعي بسيط (كروس فيت، بوكس، HIIT، يوجا،
   حديد) بالوقت والمدرّب.
7. **المدرّبون** (Team): كروت بورتريه + الاسم + التخصص (كمال أجسام، تغذية، لياقة).
8. **قبل/بعد + آراء الأعضاء** (Testimonials) بصور حقيقية.
9. **معرض الصور** (Gallery grid).
10. **CTA أخير** ضخم على خلفية صورة: «جاهز تبدأ؟» + زر اشتراك + رقم واتساب.
11. **Footer** داكن: العنوان، الخريطة، السوشيال، المواعيد.

## تفاصيل تقنية
- **Responsive موبايل أولاً** (أغلب الزوّار موبايل).
- تفاعلات لطيفة: hover على الكروت، ظهور تدريجي عند التمرير (subtle، مش مبالغ).
- **RTL عربي** بالكامل، والأرقام تنفع عربي/إنجليزي.
- إمكانية الوصول: تباين كافٍ، alt للصور، عناوين h1/h2 مرتّبة.
- سرعة: صور مضغوطة، lazy-load لغير الـHero.

## المخرجات المطلوبة
كود HTML/CSS (وTailwind لو ينفع) نظيف، قابل للنسخ في EJS، مع placeholders واضحة
للصور (نستبدلها بصور الجيم الفعلية) وللنصوص (اسم الجيم/الأسعار/المواعيد).

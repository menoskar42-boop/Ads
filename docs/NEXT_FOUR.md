بسبب الكود. اتأكد من رسالة الخطأ: لو فيها `Cannot find module` أو `requireStack`
يبقى بيئة.

## ٠) تفسير الآية بيفتح مقدمة السفر — ✅ **اتصلّح**

بلّغ عنه مستخدمون: تضغط على «تفسير الآية» فيفتح **مقدمة السفر** بدل تفسير
الآية. المالك ذكر تسالونيكي الثانية إصحاح ١ كمثال.

**اتحطّ أول لأنه باج بيشوفه مستخدمين حاليًا، والبنود التانية تحسينات.**

### قياس فعلي (٢٠٢٦-٠٨-١٠)
```
عيّنات مفحوصة (٤ آيات × أول إصحاحين × ٦٥ سفر) : 500
رجّعت مقدمة السفر بدل تفسير الآية              : 173  (35%)
أسفار متأثرة                                    : 58 من 65
```
مثال المالك مؤكَّد: تسالونيكي ثانية ١ — الآيات ١ و٣ و٥ و٨ و١٢ كلها بترجّع نفس
الـ١٤٨٥ حرف اللي هي المقدمة. الآية ٢ لوحدها بترجّع نص مختلف (٢٧١ حرف).

### المطلوب
- [x] كل آية في كل إصحاح في كل سفر تفتح تفسيرها هي.
- [x] لو الآية مالهاش تفسير مخصوص → تعرض تفسير **الإصحاح** بعلامة صريحة،
      **مش** مقدمة السفر.

### النتيجة بعد الإصلاح (نفس الـ٥٠٠ عيّنة)
```
تفسير الآية نفسها      : 324
تفسير الإصحاح (معلَّم)  : 176
مفيش حاجة              : 0
مقدمة السفر بالغلط     : 0   ← كان 173
```
الكوميت: شوف `git log --oneline -- mybible/server/tafsir-service.ts`.
**فاضل تحقّق يدوي** على الموقع بعد النشر: افتح آية في تسالونيكي ثانية ١ واتأكد
إن الملاحظة «مفيش تفسير مخصوص للآية دي — ده تفسير الإصحاح» ظاهرة فوق النص.

### إزاي
1. **مكان الباج**: `mybible/server/tafsir-service.ts` — `getVerseTafsir()`
   و`extractVerseTafsir()`. الأخيرة بتحاول تلاقي قسم الآية جوّه نص الإصحاح
   بأنماط زي `(١تس1: 3-5)` و`الآيات (3-5):`. لما تفشل، فيه **fallback بيرجّع
   النص الخام كله** — وسجل الإصحاح ١ غالبًا هو المقدمة. ده مصدر الـ35%.
2. **الإصلاح المقترح**: لما ما نلاقيش قسم للآية، ماترجّعش النص الخام. رجّع
   `null` وسيب الواجهة تقول «تفسير الإصحاح» أو «مفيش تفسير للآية دي». وفيه
   سابقة في نفس الملف: `belongsToChapter()` اتعملت بالظبط عشان تمنع عرض تفسير
   إصحاح تاني — نفس المبدأ.
3. **كاشف المقدمة**: `getBookIntro(book)` موجودة. أي نتيجة آية بتطابق أول
   ٨٠ حرف من المقدمة = خطأ، ماتعرضهاش.
4. **قِس قبل وبعد** بنفس السكربت اللي طلّع الأرقام دي (٤ آيات × أول إصحاحين ×
   كل سفر، مع استثناء المزامير لأنه بطيء) وحطّ الرقمين في رسالة الـcommit.
   لازم يوصل صفر أو قريب منه من غير ما يزيد عدد الـnull بشكل كبير.
5. **متألّفش تفسير.** لو المصدر مافيهوش تفسير للآية، الصح إنها تقول كده.

### ملفات
`mybible/server/tafsir-service.ts` · `mybible/client/src/pages/Bible.tsx`
(اللي بيعرض) · `mybible/client/src/lib/tafsir-csv-service.ts` (الجالب)
`mybible/script/audit-tafsir.ts` و`check-tafsir-alignment.ts` (أدوات موجودة)

### الحالة الحالية للتفاسير (خلفية)
١١٨٧/١١٨٩ إصحاح فيهم تفسير. الناقص: **عدد ١٩** و**حزقيال ٣** — نصّهم الصح مش
موجود في المصدر أصلاً والخانة كانت مليانة بتفسير إصحاح تاني، فاتحجبت.
وتلات أصحاحات (أخبار أيام ثاني ١٨ و٢٧، مرقس ٥) نصّهم **إحالة** كتبها المفسّر

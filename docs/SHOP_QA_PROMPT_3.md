# 🧪 برومبت QA — تتبّع الطلب + Q&A + مرتجعات + شراء سريع + تنبيهات (15-22)

> انسخ الكل لكلود إكستنشن.

---

انت QA محترف لمتجر إلكتروني. تحتاج حساب عميل + حساب تاجر. نفّذ واكتب ✅/❌ لكل حالة.

## تتبّع الطلب (15)
- اعمل طلب كعميل. افتح `/customer/orders` → اضغط «🚚 تتبّع الطلب».
- لازم يظهر **timeline** بالحالات (تم الطلب → تأكيد → بيتجهّز → شحن → في الطريق → توصيل) والحالة الحالية مميّزة.
- من لوحة التاجر (`/company/orders/:id`) غيّر حالة الطلب → ارجع لصفحة التتبّع عند العميل → الحالة اتحدّثت والـtimeline تقدّم.

## أسئلة وأجوبة (17)
- في صفحة منتج، اكتب سؤال واضغط «اسأل» → رسالة تأكيد.
- من `/company/questions` (لوحة التاجر) → لازم السؤال يظهر → اكتب رد.
- ارجع لصفحة المنتج → الرد ظاهر تحت السؤال.

## المرتجعات (20)
- على طلب حالته «تم التوصيل»، من صفحة التتبّع افتح «طلب إرجاع» واكتب سبب → إرسال.
- من `/company/questions` (قسم المرتجعات) → الطلب يظهر «قيد المراجعة» → غيّره لـ«مقبول».
- ارجع لصفحة التتبّع → الحالة اتحدّثت.

## اشترِ الآن (16)
- في صفحة منتج، اضغط «⚡ اشترِ الآن» → لازم يوديك **مباشرة للـcheckout** (مش السلة).

## تنبيهات المخزون (18)
- افتح منتج **نافد** (stock=0) → لازم يظهر «المنتج نفد — عايز نبلّغك؟» + خانة إيميل.
- اكتب إيميل واضغط «أبلغني» → رسالة تأكيد. (الإيميل الفعلي بيتبعت لما التاجر يزوّد المخزون — سيرفر لازم يكون فيه SMTP.)

## تقارير المبيعات (22)
- من لوحة التاجر افتح `/company/reports` → لازم يظهر: إجمالي الإيراد، إيراد الشهر/اليوم، عدد الطلبات، رسم بياني آخر 30 يوم، الطلبات حسب الحالة، أكثر المنتجات مبيعاً. تأكّد الأرقام منطقية مقارنة بطلباتك.

## التقرير
جدول: الحالة | متوقع | فعلي | ✅/❌. ركّز على: الـtimeline بيتقدّم صح، الردود بتظهر، حالة المرتجع بتتحدّث، والأرقام في التقارير صحيحة.

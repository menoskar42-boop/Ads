# برومبت الإكستنشن: مفاتيح الـAI المجانية فى أسرار مشروع `sf`

**Trigger:** «ابعتلي برومبت مفاتيح الـAI المجانية».

المالك عنده مفتاح Groq (`GROQ_API_KEY` مستخدم فى الكود). عايز مفاتيح مجانية من باقى المزوّدين
(من رد DeepSeek ٢٠٢٦-١١-٠٨) تتحط جاهزة فى أسرار ريبليت، وهو هيقول بعدين هنستخدمها فى إيه —
**مفيش كود بيتغيّر دلوقتى**، والأسرار مش مستخدمة فى أى مكان لحد ما يتقرّر.

| المزوّد | اسم السرّ | ليه مجانى |
|---|---|---|
| Google AI Studio (Gemini) | `GEMINI_API_KEY` | الباقة المجانية — **بشرط** مشروع جوجل كلاود من غير فوترة |
| Mistral (La Plateforme) | `MISTRAL_API_KEY` | خطة «Experiment» المجانية (تأكيد برقم موبايل) |
| OpenRouter | `OPENROUTER_API_KEY` | الموديلات اللى آخرها `:free` — والمفتاح حدّه صفر دولار |
| GitHub Models | `GITHUB_MODELS_TOKEN` | توكن fine-grained صلاحيته «Models: read» بس |

⚠️ أهم خط أحمر: مشروع مفتاح الخرايط بتاع Oscar Drive عليه فوترة. مفتاح Gemini لو اتعمل فى مشروع عليه
فوترة بيتحاسب **بفلوس** — فلازم مشروع جديد من غير فوترة.

---

```
أنت شغّال فى متصفح المالك على حساباته الحقيقية (Google · Mistral · OpenRouter · GitHub · Replit).
المطلوب: تعمل ٤ مفاتيح API مجانية وتحط كل واحد كسرّ فى مشروع Replit اسمه sf. مفيش أى كود هيتكتب.

── الخطوط الحمرا (مهمة جداً) ─────────────────────────────────────────
- 🔴 قيمة أى مفتاح ماتتكتبش فى ردّك ولا فى أى ملاحظة ولا فى أى مكان غير خانة Value فى أسرار Replit.
  فى التقرير اكتب اسم السرّ بس.
- 🔴 مفيش كارت ولا دفع ولا شراء رصيد ولا «Upgrade» ولا تفعيل فوترة. لو أى صفحة طلبت كارت أو
  اشتراك → قف عند المزوّد ده، وكمّل اللى بعده، واكتب فى التقرير إنه طلب كارت.
- 🔴 ماتغيّرش ولا تمسح أى سرّ موجود فى Replit (خصوصاً GROQ_API_KEY وأى سرّ تانى). إضافة بس.
- 🔴 مفيش Republish ولا Deploy ولا تعديل فى إعدادات النشر أو الدومين.
- 🔴 ماتلمسش أى مشروع جوجل كلاود موجود (فيه مشروع عليه فوترة لمفتاح الخرايط — ممنوع يتعمل فيه مفتاح Gemini).
- لو حاجة طلبت تأكيد برقم موبايل أو كود → اسأل المالك وهو يدخّله بنفسه.
- لو اسم سرّ من الأسماء تحت موجود أصلاً فى Replit → ماتغيّرهوش، واكتب ده فى التقرير.

── ١) Gemini — اسم السرّ: GEMINI_API_KEY ─────────────────────────────
- افتح aistudio.google.com بحساب جوجل بتاع المالك.
- «Get API key» ← «Create API key».
- لو سألك تختار مشروع: اختار «Create API key in new project» (مشروع جديد). ماتختارش مشروع موجود.
- بعد ما المفتاح يتعمل: اتأكد إن خانة الخطة/الـTier جنبه مكتوب فيها Free (مش Paid / Billing).
  لو مكتوب Paid أو فيه فوترة → امسح المفتاح ده، وقف، واكتب ده فى التقرير.

── ٢) Mistral — اسم السرّ: MISTRAL_API_KEY ───────────────────────────
- افتح console.mistral.ai وادخل (بجوجل أو إيميل المالك).
- لو طلب يختار خطة: «Experiment» (المجانية). مش «Scale».
- لو طلب رقم موبايل للتأكيد → المالك يدخّله والكود بنفسه.
- «API Keys» ← «Create new key» — الاسم: oscardevs-sf ، ومن غير تاريخ انتهاء لو الخيار موجود.

── ٣) OpenRouter — اسم السرّ: OPENROUTER_API_KEY ─────────────────────
- افتح openrouter.ai وادخل بحساب جوجل بتاع المالك.
- «Keys» ← «Create Key» — الاسم: oscardevs-sf.
- خانة «Credit limit»: حط 0 (صفر) عشان المفتاح مايصرفش أى فلوس أبداً — الموديلات المجانية
  (اللى آخرها :free) بتشتغل من غير رصيد.
- ماتشتريش رصيد (Credits) حتى لو الصفحة اقترحت.

── ٤) GitHub Models — اسم السرّ: GITHUB_MODELS_TOKEN ──────────────────
- افتح github.com/settings/personal-access-tokens/new (Fine-grained token) بحساب المالك.
- الاسم: oscardevs-sf-models · المدة: سنة (أو أطول خيار من غير «No expiration» لو مش موجود).
- Repository access: «Public repositories (read-only)» أو «No repository» — مش All repositories.
- Permissions ← Account permissions ← «Models»: Read-only. ولا أى صلاحية تانية.
- «Generate token».

── ٥) حطّ كل مفتاح فى Replit (بعد كل مزوّد على طول) ────────────────
- افتح replit.com وادخل مشروع اسمه sf (مش أى مشروع تانى).
- Tools ← Secrets ← «New Secret» (أسرار التطبيق نفسه، مش Account secrets).
- Key = الاسم بالظبط زى المكتوب فوق (حروف كبيرة وشرطة سفلية) · Value = المفتاح، والصقه مباشرة.
- اتأكد إن السرّ ظهر فى القايمة بالاسم الصح. ماتعرضش قيمته (ماتدوسش على العين).

── التقرير اللى ترجّعه ─────────────────────────────────────────────
لكل مزوّد سطر واحد:
- اسم السرّ — اتعمل واتحط فى sf / ماتعملش وليه (كارت؟ موبايل؟ موجود قبل كده؟).
- لو شُفت حدود الاستخدام المجانى على الصفحة (طلبات فى الدقيقة/اليوم) اكتبها.
- لـGemini: اكتب اسم المشروع الجديد وإن الخطة Free.
ومن غير ولا قيمة مفتاح.
```

# برومبت استهداف العملاء (Outreach Prospecting) — قالب محفوظ

> **Trigger:** لما يقول المالك **«ابعتلي برومبت استهداف العملاء»** (أو ما يماثلها) →
> أرسل البرومبت ده (مع تعديل القطاع لو طلب: منتجات / أكل / مجال معيّن).

## القواعد الثابتة
- **بحث صامت فقط** — الإكستنشن **مايبعتش** أي رسالة ولا يعمل follow/like.
- **3 عملاء** بجودة في كل مرة.
- **إنت (المالك) اللي تبعت** الرسائل يدوياً — مش الإكستنشن (حماية الحسابات).
- **2–3 رسائل في الأسبوع** كحد أقصى، مخصّصة مش بالجملة.
- يفضّل صفحات **عندها رقم واتساب ظاهر** + **معندهاش موقع**.

## البرومبت (انسخه للإكستنشن)
```
المهمة: بحث صامت عن 3 عملاء محتملين جدد (بحث وتقرير فقط — متبعتش أي رسالة ومتتفاعلش مع أي صفحة).

المعايير:
- صفحات أنشطة تجارية صغيرة في مصر [القطاع: ⟨منتجات / أكل / مجال محدّد⟩].
- نشطة (بتنشر بانتظام، آخر بوست قريب).
- عندها رقم واتساب ظاهر علناً (في البايو/معلومات الاتصال).
- معندهاش موقع إلكتروني (اتأكد من ده).

لكل عميل من الـ3، اعملي تقرير فيه:
- اسم النشاط + الرابط.
- بيبيع/بيقدّم إيه بالظبط.
- المتابعون ومدى النشاط.
- رقم الواتساب (+ رابط wa.me/<الرقم بصيغة دولية>).
- تأكيد إنه معندوش موقع (الدليل).
- نقطة الألم + إزاي الموقع/المتجر هيحلّها.

اطلّعي 3 بس بجودة. بحث صامت تماماً.
```

## ملاحظات القطاع
- **منتجات (الأفضل للمتجر):** ملابس، إكسسوارات، مكياج/عناية، شنط، أحذية، ديكور، هدايا، هاند ميد، منتجات أطفال، عطور، إكسسوارات موبايل. (استبعد الأكل/المطاعم/الحلويات).
- **أكل/مطاعم:** للنوع ده (طلبات) — لو طلب صراحةً.

## بعد التقارير
أكتب رسالة واتساب مخصّصة لكل عميل (مؤدبة + هوك + نقطة ألمه + العرض المجاني)، والمالك يبعتها يدوي.

## ٢) الملاحة جوه التطبيق — الحساب

- جوجل بتحسب **كل وجهة** (destination). **أول ١٠٠٠ وجهة فى الشهر مجانى** — والإرشاد وتحديث الزحمة وإعادة
  حساب الطريق لو غلطت مش بيتحسبوا.
- ⚠️ الـ١٠٠٠ دول **على حساب الفوترة كله** (كل الأجهزة اللى عليها التطبيق)، مش على كل جهاز. لو التطبيق
  اتنزّل على بلاى وناس كتير استخدموه، الوجهات بتاعتهم بتتحسب عليك.
- اللى فى الكود: الجهاز بيعدّ وجهاته، ولو عدّى ١٠٠٠ فى الشهر بيفتح تطبيق الخرائط (مجانى). وأى مشكلة
  (مفيش نت · مفيش خدمات جوجل على الشاشة · الشروط ماتقبلتش) ⇒ تطبيق الخرائط برضه.
- **الحماية الحقيقية من جوجل كلاود** (الخطوة ب تحت): سقف يومى للاستخدام + تنبيه ميزانية.
- محتاجة **حساب فوترة بكارت** فى Google Cloud حتى لو مش هتدفع حاجة.
- الشاشة لازم يكون عليها **خدمات جوجل** (Google Play Services) — لو مش موجودة الملاحة بتفتح تطبيق الخرائط.
- أول مرة: جوجل بتعرض **شروط الملاحة** والسواق لازم يوافق (ده شرط جوجل).
- السواق يقدر يختار من الإعدادات: «جوه Oscar Drive» أو «تطبيق الخرائط».

## ٣) المطلوب منك (بالترتيب)

### أ) مفتاح التوقيع — مرة واحدة فى العمر
مفتاح التوقيع هو «بصمة» التطبيق: من غيره كل نسخة جديدة لازم تمسح القديمة وبياناتها، وبلاى مايقبلش.
**لو ضاع، مش هتقدر تحدّث التطبيق** — احتفظ بالملف والباسورد فى مكان آمن (مش فى الكود).

فى Shell مشروع **`sf`** على ريبليت (فى `/tmp` عشان الملف مايدخلش git):
```bash
cd /tmp && (command -v keytool >/dev/null || echo "keytool مش موجود — جرّب: nix-shell -p jdk17_headless") \
&& keytool -genkeypair -v -keystore oscar-drive-upload.jks -alias oscardrive -keyalg RSA -keysize 4096 \
   -validity 10000 -dname "CN=OscarDevs, O=OscarDevs, C=EG" \
&& base64 -w0 oscar-drive-upload.jks > oscar-drive-upload.b64 && echo تم
```
هيسألك على باسورد مرتين (اكتب باسورد قوى واحفظه). وبعدين:
1. نزّل `oscar-drive-upload.jks` واحفظه عندك (درايف خاص / فلاشة).
2. GitHub ← المستودع `Ads` ← **Settings ← Secrets and variables ← Actions ← New repository secret** — أربع أسرار:
   | الاسم | القيمة |
   |---|---|
   | `ODRIVE_KEYSTORE_B64` | محتوى ملف `oscar-drive-upload.b64` كله |
   | `ODRIVE_KEYSTORE_PASSWORD` | الباسورد |
   | `ODRIVE_KEY_ALIAS` | `oscardrive` |
   | `ODRIVE_KEY_PASSWORD` | نفس الباسورد |
3. امسح الملفين من ريبليت: `rm /tmp/oscar-drive-upload.*`
4. قولّى «حطيت الأسرار» — هشغّل البناء، والـAPK اللى على الموقع هيبقى موقّع (والتحديثات تتركّب فوق بعض).

### ب) مفتاح خرايط جوجل (للملاحة جوه التطبيق) — اختيارى
1. [console.cloud.google.com](https://console.cloud.google.com) ← مشروع جديد `oscar-drive` ← اربطه بحساب فوترة.
2. APIs & Services ← Library ← فعّل **Navigation SDK** (وهيفعّل معاه Maps SDK for Android).
3. Credentials ← Create credentials ← **API key** ← Restrict key:
   - Application restrictions: **Android apps** ← اسم الحزمة `com.oscardevs.oscardrive` + بصمة SHA-1 لمفتاح التوقيع
     (أطلعها بـ `keytool -list -v -keystore oscar-drive-upload.jks`) — ولو رفعت على بلاى ضيف كمان بصمة
     «App signing key» من Play Console ← Setup ← App signing.
   - API restrictions: Navigation SDK بس.
4. **السقف:** Navigation SDK ← Quotas ← حط حد يومى (مثلاً ٣٠ فى اليوم ≈ ٩٠٠ فى الشهر).
   و Billing ← Budgets & alerts ← ميزانية ١ دولار بتنبيه.
5. GitHub Secret جديد: `MAPS_API_KEY` = المفتاح.

### ج) جوجل بلاى
1. حساب مطوّر على [play.google.com/console](https://play.google.com/console) — ٢٥ دولار مرة واحدة.
   - **حساب شخصى جديد:** جوجل بتطلب **اختبار مغلق بـ١٢ مختبِر لمدة ١٤ يوم** قبل النشر للكل.
   - **حساب منظمة (OscarDevs):** مالوش شرط الـ١٢ مختبِر، بس محتاج رقم D-U-N-S.
2. Create app ← الاسم والبيانات من القسم ٤ تحت ← Free ← App.
3. Release ← Testing (أو Production) ← Create release ← ارفع `oscar-drive.aab` من artifacts آخر run
   (GitHub ← Actions ← Oscar Drive APK ← آخر run ← `oscar-drive-play-aab`) — وفعّل **Play App Signing**.
4. App content: سياسة الخصوصية (اللينك فوق) · Ads: **لا** · Data safety (القسم ٥) · Content rating (الاستبيان:
   أداة، مفيش عنف ولا محتوى مستخدمين) · Target audience: **18+** · **Foreground service permissions**: النوع
   *Location* — «بيعرض السرعة ويقيس الرحلة وينبّه السواق صوتياً وهو سايق والتطبيق فى الخلفية ورا الخرايط»
   + فيديو قصير من الشاشة.
5. **Screenshots:** لازم صور حقيقية من التطبيق (٢ على الأقل، بالعرض). صوّرها من شاشة العربية أو موبايل
   (زرار الباور + الصوت) — **أنا ماقدرش أصوّر التطبيق هنا** (مفيش أندرويد فى بيئتى)، وصور متخيّلة ممنوعة.

## ٥) Data safety (الإجابات)

- **هل التطبيق بيجمع أو بيشارك بيانات؟** التطبيق نفسه: لأ — كل حاجة على الجهاز (المعالجة على الجهاز بس
  مابتتحسبش «جمع» فى تعريف جوجل). **بس** مكتبة Google Navigation SDK (لما الملاحة جوه التطبيق شغّالة)
  بتبعت لجوجل: **الموقع الدقيق والتقريبى** + بيانات أداء التطبيق (crash/diagnostics) + معرّفات الجهاز —
  الغرض: App functionality / Analytics (من جوجل)، مشفّرة فى النقل، ومش اختيارية وقت الملاحة.
  ⚠️ راجع صفحة جوجل «Navigation SDK — Google Play data disclosure» قبل ما تملا الفورم؛ لو المفتاح
  ماتحطش خالص (الملاحة بتفتح تطبيق الخرائط) التطبيق مابيبعتش حاجة.
- **لو «الحماية والتتبّع» موجودة فى النسخة اللى هترفعها (اختيارية ومقفولة افتراضياً):** Location (precise) — Collected،
  الغرض App functionality، optional (المستخدم بيشغّلها)، مش بيتشارك مع طرف تالت. Photos and videos — مش بيتجمع
  (الفيديو بيفضل على الجهاز). ولازم «Prominent disclosure» قبل التشغيل — موجود فى شاشة الحماية والسياسة.
- **التشفير فى النقل:** نعم (HTTPS بس).
- **حذف البيانات:** المستخدم بيمسحها بمسح التطبيق/بياناته — مفيش حساب ولا سيرفر.

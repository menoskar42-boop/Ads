## 🔧 Scripts بديلة لو محتاج تجيب الصور بطرق تانية

### 1. Python + Wikimedia (Public Domain Tech Photos)
```python
import requests, os
products = {
    'iphone-15-pro-max': 'IPhone_15_Pro_Max_Natural_Titanium',
    'galaxy-s24-ultra':  'Samsung_Galaxy_S24_Ultra',
    # ... إلخ
}
for slug, query in products.items():
    url = f'https://commons.wikimedia.org/wiki/Special:FilePath/{query}.png?width=800'
    r = requests.get(url, headers={'User-Agent':'Mozilla/5.0'})
    if r.status_code == 200:
        with open(f'{slug}.png','wb') as f: f.write(r.content)
```

### 2. Unsplash API (مجاناً مع key)
```bash
# سجّل في https://unsplash.com/developers واطلب API key
curl -H "Authorization: Client-ID YOUR_KEY" \
  "https://api.unsplash.com/search/photos?query=iphone+15+pro+max&per_page=1" \
  | jq -r '.results[0].urls.regular'
```

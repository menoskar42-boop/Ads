# 🧪 برومبت QA — نظام إدارة العيادات

> انسخ الكل وابعته لكلود إكستنشن — يختبر العيادة (العام + الإدارة) كـQA محترف.

---

انت مُختبِر جودة (QA) محترف لنظام إدارة عيادات. فيه جزئين: **الصفحة العامة** (اللي
يشوفها المريض) و**لوحة الإدارة** (`/clinic`). استخدم العيادة التجريبية:
- الصفحة العامة: `https://clinic.oscardevs.com` (لو مش شغّالة، بلّغني — ممكن تكون محتاجة نشر/ربط نطاق).
- دخول الإدارة: `oscardevs.com/company/login` ببيانات: `clinic@demo.oscardevs.com`  / «اطلب بيانات الدخول من المالك — مش مكتوبة في المستودع».

نفّذ كل الاختبارات، واكتب لكل حالة ✅/❌ + اللي حصل. صوّر أي خطأ.

## أولاً: الصفحة العامة (المريض)
1. الصفحة الرئيسية للعيادة: اسم العيادة (h1 واحد)، التخصص، قائمة الأطباء ككروت.
2. اضغط طبيب → تفتح صفحته (اسمه، نبذته، سعر الكشف، مواعيده) وفيها زر حجز.
3. **الحجز:** املأ نموذج الحجز (اسم + موبايل + اختيار طبيب) واضغط إرسال → لازم تظهر رسالة نجاح.
   - جرّب موبايل قصير/فاضي → لازم يرفض.
4. تأكّد **مفيش إعلانات** على أي صفحة عيادة (صفحات طبية).
5. الكود المصدري: `<title>` ≤ 60 حرف تقريباً، فيه `MedicalClinic`/`Physician` schema (للعيادات غير التجريبية).

## ثانياً: لوحة الإدارة (`/clinic`) — بعد تسجيل الدخول
**الطابور (`/clinic/queue`):**
- سجّل «تسجيل وصول» لمريض (مسجّل أو جديد) + اختر طبيب/نوع زيارة + علّم «عاجل».
- المريض يظهر في الطابور، والعاجل يظهر فوق. حرّكه: انتظار → دخول الكشف → إنهاء.

**المرضى + الملف الإكلينيكي:**
- `/clinic/patients` → أضف مريض. اضغط عليه → يفتح ملفه.
- في الملف: سجّل **علامات حيوية** (ضغط/نبض/حرارة…) → تظهر في السجل.
- أضف **ملاحظة إكلينيكية** → تظهر.
- أضف **روشتة** بأكثر من دواء (زر «+ دواء آخر») → تتحفظ وتظهر.
- عدّل «التشخيص» لزيارة → يتحفظ.

**الخدمات والفواتير:**
- `/clinic/services` → أضف خدمة (بسعر ونسبة طبيب) + نوع زيارة.
- `/clinic/invoices` → أنشئ فاتورة من خدمة/بند يدوي + خصم → تفتح صفحة الفاتورة.
- سجّل **دفعة جزئية** → الحالة «مدفوعة جزئياً» والمتبقّي صحيح؛ ثم دفعة تكمّل → «مدفوعة» بالكامل.
- **راجع الحساب يدوياً**: المجموع − الخصم = الإجمالي؛ المدفوع والمتبقّي صح.
- زر **طباعة** الفاتورة يفتح نسخة نظيفة.
- `/clinic/finance` → التقارير: تحصيل اليوم/الشهر، حسابات الأطباء (نصيب الطبيب)، طرق الدفع.

**الأطباء والمواعيد والإعدادات:**
- `/clinic/doctors` → أضف/عدّل/احذف طبيب (كل طبيب له صفحة عامة تلقائياً).
- `/clinic/appointments` → أكّد/ألغِ حجز؛ زر واتساب (لو مفعّل).
- `/clinic/settings` → عدّل بيانات العيادة واحفظ.

**الوحدات المتقدّمة (لو مفعّلة من أدمن الصف الأول):**
- المخزون: أضف صنف + اعمل «صرف» → الكمية تنقص.
- التأمين / الفروع / الموظفون (حضور/انصراف) / مركز الاتصال / API / واتساب — افتح كل تبويب وتأكّد إنه بيفتح ويحفظ من غير خطأ.

**الأمان/SEO:**
- كل صفحات `/clinic/*` لازم تكون `noindex,nofollow` (شوف الميتا) ومن غير إعلانات.
- لو فتحت `/clinic` من غير تسجيل دخول → يوجّهك للّوجين.

أي صفحة بترجع خطأ، أي بيانات مابتتحفظش، أو ظهور إعلان/فهرسة على صفحة طبية.

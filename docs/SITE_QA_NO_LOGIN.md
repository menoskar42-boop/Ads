# 🧪 برومبت QA شامل — كل الصفحات (بدون تسجيل دخول)

> برومبت واحد يختبر الموقع كله من غير أي كلمة سر. (صفحات الدخول في
> `SITE_QA_LOGIN.md`.) انسخه كله لكلود إكستنشن.

---

انت QA محترف. هتختبر منصّة OscarDevs **كلها من غير ما تسجّل دخول بأي حساب** (ممنوع
تدخل باسورد). لكل صفحة تأكّد: بتفتح (مش 500/شاشة بيضا)، العربي ظاهر صح، الروابط
والأزرار شغّالة. اكتب لكل قسم جدول: الصفحة | ✅/❌ | ملاحظة. صوّر أي خطأ.

## 1) الموقع الرئيسي (oscardevs.com)
افتح وتأكّد إنها 200 ومحتواها ظاهر:
`/` · `/about` · `/faq` · `/help` · `/our-work` · `/blog` (+ افتح أي مقال) ·
`/apply` (جرّب تغيّر نوع النشاط: متجر/عيادة/مطاعم/جيم → الفورم يتحدّث) ·
`/privacy` · `/terms` · `/contact`.
- في `/contact`: املأ بإيميل واسم ورسالة → رسالة نجاح. جرّب رسالة فيها 3 لينكات (المفروض تتحجب كسبام).
- الشعار «OscarDevs» ظاهر أعلى الشمال، وكل كروت الخدمات وأزرار «اطلب/شاهد نموذج حي» شغّالة.

## 2) المتجر الإلكتروني — delta.oscardevs.com
- **البحث اللحظي:** اكتب حروف → اقتراحات بصور وأسعار.
- **الفلترة/الترتيب:** الأرخص/الأغلى + نطاق سعر + «متوفر فقط».
- **تعدّد العملات:** لو فيه محوّل عملة، بدّل العملة → الأسعار تتحوّل فوري.
- **صفحة المنتج:** زوم الصورة، تقييمات، «قد يعجبك»، أسئلة وأجوبة، «⚡ اشترِ الآن»، وزر «اشترك» لو المنتج قابل للاشتراك، وزر واتساب لو متفعّل.
- **صفحة الهبوط:** خُد رابط منتج وبدّل `/product/` بـ`/lp/` → لازم تفتح صفحة هبوط بزر «اطلب الآن»، وفي كودها `noindex` + `canonical` لصفحة المنتج.
- **دورة الشراء:** ضيف منتج → السلة → checkout → **راجع ملخص الطلب والإجمالي** (منتجات + شحن). (مش لازم تأكّد الطلب فعلياً.)

## 3) الصيدلية — pharmacy.oscardevs.com
تصفّح الأدوية، ابحث عن دواء، جرّب **زر «أضف» بالماوس العادي** (لازم يشتغل ويظهر شريط السلة)، وتتبّع الطلب.

## 4) المطاعم — orders.oscardevs.com
افتح الشات 🤖 واختبر موظف الاستقبال الذكي:
- اطلب أكل (برجر + مشروب) → يضيف صح ويحسب الإجمالي.
- اسأل سؤال استفهامي → ماينفعش يضيف حاجة.
- قول «شيل المشروب» → **لازم يتشال فعلاً من السلة** (افتح السلة وتأكّد).

## 5) العيادة — clinic.oscardevs.com
- الصفحة تفتح (أطباء + حجز). اضغط طبيب → صفحته. 
- **الحجز:** املأ اسم + موبايل واضغط إرسال → رسالة نجاح. جرّب موبايل قصير (123) → **لازم رسالة خطأ ظاهرة** (مش صفحة فاضية).
- تأكّد مفيش إعلانات على صفحات العيادة.

## 6) الجيم — gym.oscardevs.com
- الصفحة تفتح: Hero + شريط أرقام + مميزات + **باقات الاشتراك** + **جدول الكلاسات** + المدرّبون + CTA.
- **حجز كلاس:** افتح «احجز مكانك» تحت أي كلاس → املأ اسم + موبايل → تأكيد → رسالة «تم الحجز» (أو «قائمة انتظار» لو ممتلئ).
- **تسجيل حضور:** افتح `gym.oscardevs.com/checkin` → جرّب كود/موبايل غلط → رسالة «مالقيناش عضو». (الكود الصحيح بيتجرّب في برومبت الدخول.)

## 7) فحوص عامة (SEO/سلامة) — من غير لوجين
- الصفحات الخاصة `oscardevs.com/customer/login` و`/company/login` و`/customer/register`: تفتح شكلياً صح وميتاها **noindex**. (متسجّلش دخول.)
- الصفحات العامة (الرئيسية/المدوّنة/المنتجات/الجيم) فيها `<title>` و`meta description`، والعناوين قصيرة (≤ ~60 حرف).
- مفيش أي صفحة بترجع 500 أو شاشة بيضا طول الاختبار.

## التقرير النهائي
لكل قسم: كام ✅ وكام ❌، وأهم المشاكل (مع صور). بلاغ عاجل على: صفحة بترجع 500،
زر/فورم مش شغّال، حذف شات المطاعم مش بيتنفّذ، أو خطأ في أي إجمالي.

## 1) لوحة تاجر المتجر (Delta)
افتح وتأكّد إن كل تبويب يفتح ويحفظ: المنتجات (+ استيراد CSV، + في فورم المنتج فعّل
«الاشتراك المتكرر») · التصنيفات · العروض · الكوبونات · **كروت الهدايا** · **سلات
متروكة** · الشحن (+ **تكامل شركة شحن**: اختر «إدخال يدوي») · التقارير · **تحليلات
المتجر** · التسويق (Pixel/Feed + رقم واتساب) · **تعدّد العملات** (أضف USD) · **صفحات
هبوط** · **الاشتراكات** · مميزات المتجر · أسئلة ومرتجعات.
- في **الطلبات**: افتح طلب → غيّر الحالة، وجرّب **«إنشاء شحنة / إدخال AWB»** (يدوي).

## 2) حساب العميل
`/customer/orders` (تتبّع/timeline) · `/customer/addresses` · `/customer/points`
(+ **رصيد المحفظة** — جرّب تفعّل كود كرت هدية) · `/customer/wishlist` ·
`/customer/subscriptions` (لو فيه اشتراك).

## 3) لوحة العيادة (/clinic)
- الطابور: تسجيل وصول + عاجل يظهر فوق + تحريك الحالة.
- المرضى: أضف مريض → ملفه → علامات حيوية + ملاحظة + روشتة + تشخيص.
- الفواتير: فاتورة من خدمة + خصم → **اختَر طبيب** → دفعة جزئية ثم كاملة (**راجع الحساب**).
  ثم `/clinic/finance` → **حسابات الأطباء لازم تظهر نصيب الطبيب**.
- المواعيد: أكّد/ألغِ + **زر واتساب** موجود. المخزون/الخدمات/الإعدادات تفتح وتحفظ.

## 4) لوحة الجيم (/gym)
- **اللوحة:** أعضاء نشطين/قرب ينتهي/منتهي + إيراد الشهر + قائمة «قرب ينتهي» بزر واتساب.
- **الأعضاء:** أضف عضو → بيع اشتراك بباقة → الحالة «نشط حتى…». اضغط اسم العضو →
  صفحته → **سجّل قياس** (وزن/دهون) ويظهر في جدول التقدّم. جرّب تجميد/تنشيط.
- **الباقات/المدرّبون (+عمولة%)/الكلاسات:** أضف/احذف.
- **نقطة البيع:** أضف منتج → سجّل بيع باختيار مدرّب → **راجع: المخزون نقص، والعمولة
  اتحسبت** وظهرت في «عمولات المدرّبين».
- **الحضور/الحجوزات:** افتح التبويبين واتأكّد إنهم بيعرضوا البيانات.
- **الحضور بكود صحيح:** افتح `gym.oscardevs.com/checkin` واكتب كود عضو نشط أضفته →
  رسالة «تم تسجيل حضورك».

## 5) لوحة الصيدلية والمطاعم
- صيدلية (`/pharmacy`): المخزون/الطلبات/الإعدادات تفتح وتحفظ.
- مطاعم (`/food`): الأصناف/الطلبات تفتح وتحفظ.

## فحوص أمان
كل صفحات اللوحات لازم `noindex,nofollow` ومن غير إعلانات. فتح أي `/company/*` أو
`/gym/*` أو `/clinic/*` من نافذة **مش مسجّلة دخول** → يوجّه للّوجين.

جدول: الشاشة | الإجراء | متوقع | فعلي | ✅/❌. بلاغ عاجل على: خطأ في أي حساب
(فواتير/عمولة/محفظة/إجمالي)، بيانات مابتتحفظش، أو صفحة بترجع خطأ.

## بعد ما الملف يوصل

كلود بيقارن النص بالمرجع (عدد الآيات + أول وآخر آية لكل إصحاح)، ولو تمام بيستبدل `mybible/data/deutero/المكابيين الثالث.json`
بالنص الجديد ومصدره، والجروب وقسم أرثوذكسيات بيعرضوه. الفرع `deutero-3macc-import` يتمسح بعدها.

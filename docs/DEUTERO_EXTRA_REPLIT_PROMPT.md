# برومبت Replit Agent: المزمور ١٥١ وصلاة منسى والمكابيين الثالث من الأنبا تكلا

> طلب المالك ٢٠٢٦-١١-٠٢: عضو فى جروب درس مار مرقس قال «مزمور ١٥١ منسى». الجروب بيجيب الأسفار القانونية
> التانية من St-Takla (`server/deutero.ts` — ٧ أسفار بس) وبعدها النسخة المحفوظة (`data/deutero/sttakla-1877.json`)،
> والاتنين مافيهمش الأسفار التلاتة دى. مؤقتاً الجروب بيعرض نص قسم «أرثوذكسيات» (`apocrypha-content.ts`)، والمكابيين
> الثالث فيه ناقص إصحاحات. البرومبت ده بيجيب النص من الأنبا تكلا زى باقى الأسفار، فى ملف لوحده على فرع لوحده،
> وكلود بيحطه فى `data/deutero` بعد ما يراجعه.
> بيئة كلود مقفول فيها st-takla.org، والإكستنشن مالوش مسار عندنا للأسفار دى، فالجلب من Replit Agent فى مشروع `sf`.
> **Trigger:** «ابعتلي برومبت مزمور ١٥١».

```
مهمتك: تجيب نص ٣ أسفار من موقع الأنبا تكلا (st-takla.org) بالحرف زى ما هو على الصفحة، وتحطه فى
ملف JSON واحد، وترفعه على GitHub فى فرع جديد لوحده. قراية بس من الموقع ده.

الأسفار المطلوبة:
1) المزمور 151 — إصحاح واحد
2) صلاة منسى — إصحاح واحد
3) المكابيين الثالث — 7 إصحاحات

خطوط حمرا (ممنوع تتخطّاها):
- ماتعدّلش أى ملف فى المشروع (~/workspace)، وماتعملش commit ولا push منه، وماتغيّرش الفرع بتاعه.
- ماتلمسش الـSecrets ولا قاعدة البيانات، وماتشغّلش السيرفر، وماتعملش Republish.
- النص من st-takla.org بس. لو سفر أو إصحاح مش موجود هناك اكتب إنه مش موجود، وماتجيبهوش من أى
  موقع تانى، وماتكتبش ولا آية من عندك أو من ذاكرتك.
- النص بالحرف زى ما هو على الصفحة: ماتصلّحش إملاء ولا تشكيل ولا ترقيم، وماتدمجش آيات ولا تقسّمها.
- طلب واحد كل 3 ثوانى على الأقل.

الخطوة 1 — دوّر على صفحات الأسفار التلاتة وهات رابط كل إصحاح. ابدأ من فهرس الأسفار القانونية التانية:
  https://st-takla.org/pub_Deuterocanon/Deuterocanon-Apocrypha_El-Asfar_El-Kanoneya_El-Tanya__0-index_.html
وباقى الأسفار القانونية التانية عندهم تحت:
  https://st-takla.org/pub_oldtest/Arabic-Old-Testament-Books/
(مثال: طوبيا إصحاح 1 = 17-Tobit/Sefr-Tobiet-Chapter-01.html)
المزمور 151 ممكن يكون مع سفر المزامير أو فى قسم لوحده — دوّر فى الفهرس وفى صفحات المزامير.

الخطوة 2 — لكل إصحاح: نزّل الصفحة واستخرج الآيات (رقم الآية + نصها بالحرف). وكل ما تخلّص سفر
اطبعلى: عدد الإصحاحات، وعدد الآيات فى كل إصحاح، وأول آية وآخر آية بنصهم.

الخطوة 3 — احفظ كل حاجة فى الملف /tmp/sttakla-extra.json بالشكل ده بالظبط (الأسماء زى ما هى):
{
  "source": "St-Takla.org",
  "fetchedAt": "<التاريخ والوقت>",
  "books": [
    { "name": "المزمور 151", "chapters": [
      { "chapter": 1, "sourceUrl": "<رابط الصفحة>", "verses": [ { "verse": 1, "text": "<النص>" } ] }
    ] },
    { "name": "صلاة منسى", "chapters": [ ... ] },
    { "name": "المكابيين الثالث", "chapters": [ ... ] }
  ],
  "missing": [ "<أى سفر أو إصحاح مالقيتوش، ولو مفيش سيبها فاضية []>" ]
}

الخطوة 4 — ارفع الملف ده بس فى فرع جديد من نسخة مؤقتة (مش من ~/workspace). شغّل دول بالترتيب فى الـShell:
cd /tmp && rm -rf deutero-extra && git clone --depth 1 --branch claude/build-oscardevs-ads-mvp-8krfN "$(git -C ~/workspace remote get-url origin)" deutero-extra
cd /tmp/deutero-extra && git checkout -b deutero-extra-import
mkdir -p mybible/data/deutero/import && cp /tmp/sttakla-extra.json mybible/data/deutero/import/sttakla-extra.json
git add mybible/data/deutero/import/sttakla-extra.json && git commit -m "deutero: المزمور 151 وصلاة منسى والمكابيين الثالث من St-Takla"
git push origin deutero-extra-import
لو أى أمر طلّع error: اقف، واكتبلى الرسالة زى ما هى، وماتجرّبش طريقة تانية.

الخطوة 5 — قولّى فى الآخر:
- لكل سفر: لقيته ولا لأ، ورابط صفحاته، وعدد الإصحاحات والآيات.
- أى حاجة فى missing.
- اتعمل push ولا لأ، واسم الفرع.
```

# خطة محتوى مدوّنة OscarDevs + معيار الجودة

> الهدف: نشر **2–3 مقالات أصلية قوية أسبوعياً** بجودة ثابتة. كل مقال لازم يعدّي
> "معيار المقال القوي" تحت قبل ما يتنشر. مفيش محتوى مولّد بالجملة أو حشو.
> (متوافق مع `docs/ADSENSE_POLICIES.md` و `docs/SEO_GUIDE.md`.)

---

## ✅ معيار "المقال القوي" (Checklist قبل النشر)
1. **يحلّ مشكلة محدّدة** لجمهورنا (صاحب مشروع صغير: متجر/مطعم/بورتفوليو) — مش موضوع عام مبهم.
2. **أصلي ومن خبرة عملية** (E-E-A-T) — أمثلة وأرقام وتفاصيل واقعية، مش كلام إنشائي.
3. **800–1500 كلمة**، بنية واضحة: مقدّمة تجذب + عناوين H2/H3 + نقاط/قوائم + خلاصة.
4. **قابل للتطبيق فوراً** — خطوات محدّدة، مش نصائح فضفاضة.
5. **اللهجة** مصرية بسيطة ودّية (نفس صوت المقالات الحالية).
6. **2–4 روابط داخلية** لمقالات/صفحات ذات صلة + **دعوة للفعل** لـ`/apply`.
7. **ميتاداتا فريدة:** `title` + `metaDescription` + `excerpt` + `tldr` + `readMins`.
8. **يستهدف عبارة بحث حقيقية** (long-tail) بشكل طبيعي — **بدون حشو كلمات**.
9. **بدون وعود كاذبة** أو محتوى مضلّل (سياسة AdSense).

## 🗓️ الإيقاع
- 2–3 مقالات أسبوعياً، بتواريخ واقعية (مش دفعة واحدة).
- نتابع التوازن بين الفئات تحت.

## 🛠️ خطوات النشر (لكل مقال)
1. اكتب الجسم في `src/views/blog/articles/<slug>.ejs` (HTML داخلي: `<h2>`, `<p>`, `<ul>`, `<blockquote>`).
2. أضف ميتاداتا في `src/routes/blog_articles.js` (slug, title, excerpt, metaDescription, date, readMins, tldr).
3. تأكّد من الروابط الداخلية + الدعوة للفعل.
4. تحقّق: render للمقال + صلاحية الـJSON-LD، ثم commit + push.

## 🔎 مقالات «أفضل برنامج …» (نية شرائية) — البند ٩٥

الفرق بينها وبين صفحات القطاعات: الصفحة بتجاوب «إيه ده»، والمقال بيجاوب
«أنهي واحد أختار». الصيغة المتفق عليها: **معايير مقارنة يقيس بيها القارئ أي
برنامج**، وبعدين قسم صريح بيقول إحنا بنغطّي منها إيه وإيه اللي لسه — من غير
ادعاء «إحنا الأفضل» (وعد مايتحققش منه، ومخالف لسياسة أدسنس، والقارئ اللي
بيقارن مش بيصدّقه أصلاً).

# Oscar Security — الحماية والتتبّع (Oscar Drive)

> المالك (٢٠٢٦-١١-٠٥): «مانع السرقة ينفع يشتغل جزئى — تحديد الموقع هيشتغل لأن فيه GPS، ولو الإنترنت اتوصل
> (حتى من السارق) نكمّل باقى المميزات»، و«صفحة ويب جنب تطبيق الأندرويد»، و«نفترض إن الكاميرا ظاهرة على الأندرويد».

## الحدود (مكتوبة للمالك بصراحة)
- الشاشة بتفصل مع إطفاء العربية ⇒ مفيش تتبّع والعربية مطفية. اللى بيظهر = آخر مكان قبل الإطفاء.
- النت من هوت سبوت الموبايل ⇒ لو العربية اتسرقت والموبايل مش فيها، الشاشة بتسجّل محلياً وبتبعت أول ما أى نت يتوصل.
- لو حد فصل الشاشة، التسجيل بيقف. ده نظام مساعد، مش جهاز تتبّع مستقل.

## الأجزاء
| الجزء | الملف |
|---|---|
| منطق الحماية (الرقم السرى · مهلة ٤٥ ث · حركة ≥ ١٠ كم/س أو ٨٠ م) + كل إمتى نسجّل | `oscardrive-android/.../logic/SecurityLogic.kt` (متختبر) |
| الطوابير على الشاشة (أماكن · أحداث · تسجيلات) | `Db.kt` (نسخة ٢ — الترقية بتسيب البيانات القديمة) |
| التنسيق + الإرسال كل ٣٠ ث + وضع الحماية من الموبايل (رقم نسخة) | `Guard.kt` · `Cloud.kt` |
| الكاميرا (Camera2 + MediaRecorder، من غير صوت، آخر ٦٠٠ ميجا) | `CamRecorder.kt` |
| شاشة 🛡️ الحماية + طلب الرقم السرى مع التشغيل | `MainActivity.kt` |
| السيرفر (drive.oscardevs.com): تسجيل الشاشة · الدفعات · الربط بكود ٦ أرقام · الإشعارات · «انقطع الاتصال» | `src/routes/drive_site.js` · `src/drive/*` |
| صفحة المالك (PWA) | `drive-web/` |
| الاختبارات | `test/oscar_security.test.js` (منطق + قاعدة حقيقية + HTTP) · `logic-test` (Kotlin) |
| الحارس | `node scripts/check-oscardrive.js` |

## الأمان
- توكن الشاشة وتوكن كل موبايل متخزّنين **هاش** بس. الربط بكود ٦ أرقام، ١٠ دقايق، مرة واحدة، و١٠ محاولات/١٠ دقايق لكل عنوان.
- تغيير الحماية من الشاشة بيتطبّق بس لو الشاشة شايفة آخر نسخة — لو المالك غيّرها من الموبايل فى النص، الموبايل يكسب.
- الكل اختيارى: «الحماية والتتبّع» مقفولة افتراضياً، والكاميرا بإذن منفصل.

## المطلوب علشان يشتغل على الموقع
1. pull + Republish (الجداول `od_*` بتتعمل لوحدها مع التشغيل).
2. `drive.oscardevs.com` لازم يوصل للسيرفر زى `speed.oscardevs.com` (نفس الإعداد — لو speed شغّال، drive هيشتغل).
3. الإشعارات بتستخدم مفاتيح VAPID الموجودة (`VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY`).

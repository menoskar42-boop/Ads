آخر تحديث: ٢٠٢٦-٠٨-١٠ · الفرع: `claude/build-oscardevs-ads-mvp-8krfN`

## ١) المشروع إيه

**OscarDevs** — منصّة سعودية/مصرية بالعربي بتدّي لكل عميل **موقع + نظام إدارة**
على ساب دومين خاص بيه (`<slug>.oscardevs.com`). ريبو واحد فيه المنصّة وكذا
منتج مستقل.

## ٢) المعمار في سطور

- **Express 4 + EJS + Postgres**، مافيش build step للمنصّة. `server.js` هو
  المدخل وفيه ترتيب الـmiddleware — **الترتيب ده حسّاس**
  (`scripts/check-route-order.js` بيحرسه).
- **توجيه المستأجرين**: `src/middleware/tenant.js` بياخد الساب دومين ويدوّر
  `WHERE slug = $1 AND is_active = true`، ويحطّ `req.tenant`. اللي بعده
  `src/routes/tenant.js` بيختار القالب حسب `page_type`.
- **٢١٧ جدول**. الـDDL في `server.js` جوّه `initDb()`. أي `ALTER` لازم يجي
  **بعد** الـ`CREATE` المقابل (`check-schema-order.js`).
- **بوول واحد مشترك**: `src/lib/shared_pool.js` بيرقّع `pg.Pool` فكل
  `new Pool()` لنفس الـconnection string بيشارك بوول واحد محدود بـ20. اتعمل
  لأن ٨١ استدعاء `new Pool()` كانوا بيستنفدوا الاتصالات ويدّوا 500.
- **i18n**: عربي/إنجليزي. `scripts/check-i18n.js` بيفشل لو مفتاح موجود في لغة
  وناقص في التانية.
- **الجلسات** في Postgres (`src/lib/pg_session_store.js`).

### مهام دورية داخلية (`server.js` آخر الملف)
بتشتغل جوّه التطبيق كل ساعة: إشعارات NeuroPilot، تجديد الاشتراكات، تذكيرات
كاكيبو، تنبيهات المخزون، مزامنة الأدوية.
⚠️ **مهم:** فيه راوتات خارجية (`/api/*/run-daily`) محميّة بـ`PUSH_CRON_SECRET`
وبترجّع **503 بالتصميم** لو السر مش متظبّط. دي **احتياطي** لاستضافة بتنام
(Autoscale). الموقع دلوقتي على **Reserved VM** مابينامش، فالمهام الداخلية
شغّالة والـ503 دي **مش عطل**. متتلخبطش زي ما أنا اتلخبطت وقلت للمالك إن تجديد
الاشتراكات واقف — كان غلط.

## ٣) 🔴 خمس حاجات اتعلّمتها بالطريقة الصعبة

**١) الـShell بتاع Replit بيوصل لقاعدة بيانات غير اللي الموقع المنشور بيقرا
منها.** ضيّعت ساعات هنا. `psql "$DATABASE_URL"` في الـShell قال إن الشركة موجودة
ومفعّلة، والموقع الحي بيدّي 404 — **الاتنين صح**. أي حاجة لازم تتكتب في قاعدة
الإنتاج تتعمل **من جوّه الموقع** (زي `/admin/demos`) مش من الـShell.
والفحص الوحيد اللي مايتخدعش:
```bash
node scripts/check-demo-links.js --http
```
النسخة اللي بتسأل قاعدة البيانات قالت «١٢ لينك سليم» وستة منهم كانوا 404.

**٢) البيئة دي مش بتنزّل حزم.** `npm install` بيفشل (الـlockfile فيه روابط
لـ`package-firewall.replit.local`، و`xlsx` من CDN محجوب). يعني `seo-audit`
و`render-clinic-pages` و`render-kakeibo-pages` و`check-async-routes` ممكن يفشلوا
عندك **بسبب البيئة**. لو الخطأ فيه `Cannot find module` أو `requireStack` يبقى
بيئة مش كود — قول كده صراحةً بدل ما تدّعي إنك شغّلت الفحص.

**٣) الشبكة محجوبة برّه.** `403 CONNECT` على أغلب الدومينات وعلى `oscardevs.com`
نفسه. يعني مش هتقدر تختبر الموقع الحي — اطلب من المالك يشغّل `curl` أو استخدم
إكستنشن المتصفح. `registry.npmjs.org` و`github.com` شغّالين.

**٤) الفرع.** الرفع دايماً على `claude/build-oscardevs-ads-mvp-8krfN` مهما قالت
إعدادات الجلسة. الـstop hook هيفضل يقول «unpushed commits» لأنه بيقارن **اسم
الفرع** المحلي — تجاهله بعد ما تتأكد إن الريموت على نفس الـcommit:
```bash
git push origin HEAD:refs/heads/claude/build-oscardevs-ads-mvp-8krfN
```

**٥) شغل مش معمولّه commit ممكن يضيع.** حصل معايا: تبديل فرع في نص الجلسة مسح
تعديلات كنت لسه ماعملتش لها commit، والكوميت طلع فيه ملف واحد بس من ستة.
**اعمل commit بعد كل جزء يخلص، مش في الآخر.**

## ٤-أ) الـCSS مبني عندنا (مهم لأي جلسة بتعدّل قوالب)

من ٢٠٢٦-٠٨-١٩ الموقع **مابيحمّلش تايلويند من الـCDN**. فيه ملف مبني ومرفوع
في الريبو:

```
npm run build:css      # tailwindcss -c tailwind.config.js -i src/styles/tailwind.css -o public/css/tw.css --minify
```

**لو ضفت كلاس تايلويند جديد في قالب، شغّل الأمر ده واعمل commit للملف.**
`node scripts/check-tailwind-build.js` بيرسم ١٦٢ صفحة وبيتأكد إن كل كلاس فيها
له قاعدة في الملف — فلو نسيت، الفحص بيقع باسم الكلاس والصفحة.

وألوان القطاعات (العيادة سماوي، الموبيليا خشبي، القاعة وردي…) بقت **متغيّرات
CSS** في `:root` بتاع كل قسم، مش `tailwind.config` في كل صفحة — عشان ملف واحد
مبني يخدم كل الأقسام.

## ٤) نظام الفحوص — استعمله، هو أحسن صديق

`node scripts/check-all.js` بيشغّل ١٣ فحص. كل واحد فيهم اتكتب **بعد** باج
حقيقي، والتعليق اللي فوقه بيحكي الباج ده — اقراه قبل ما تعدّل.

| الفحص | بيمنع إيه |
|---|---|
| `check-i18n` | مفتاح ترجمة في لغة وناقص في التانية |
| `check-schema-order` | `ALTER` قبل `CREATE` |
| `check-schema-columns` | `INSERT` في عمود مش موجود |
| `check-async-routes` | خطأ async بيعلّق الطلب |
| `check-page-types` | نوع نشاط ناقص في مكان من ٧ |
| `check-route-order` | راوت عام واقع ورا حارس دخول |
| `check-shared-pool` | استنفاد اتصالات + كلمة سر فاضية |
| `check-no-secrets` | بيانات دخول في الكود |
| `check-demo-links` | لينك «شاهد نموذج حي» بيدّي 404 |
| `seo-audit` | مخالفات SEO/AdSense في الصفحات العامة |

**لو صلّحت باج، اسأل نفسك: فيه فحص كان هيمسكه؟ لو لأ، اكتبه.** ده النمط
المتبع في الريبو ده.

### أدوات mybible
```bash
cd mybible
npx tsx script/audit-tafsir.ts              # تغطية التفاسير: سفر وإصحاح
npx tsx script/check-tafsir-alignment.ts    # نص الإصحاح ده بتاعه فعلاً؟
npm run check                               # tsc (فيه ~16 خطأ سابق للتعديل)
```

## ٥) mybible — مشروع لوحده

`mybible/` فيه تطبيق كامل (Express + React + Drizzle + Vite). اقرا
`mybible/CLAUDE.md` و`mybible/docs/TAFSIR_DATA.md` قبل أي شغل فيه.

**فيه إيه:** الكتاب المقدس كامل + تفاسير (١١٨٧/١١٨٩ إصحاح) + الأجبية +
القطمارس + السنكسار + الألحان + شاشة عرض للقداس (`/liturgy-control` و
`/liturgy-display`) + قسم أطفال + مجتمع مدارس الأحد.

**⛔ خط أحمر:** المالك قال **متلمسش قسم مجتمع مدارس الأحد**. لو عدّلت فيه
بالغلط، رجّعه.

**التفاسير:** ملفات CSV في `client/public/tafsir-parts/` (١٢٤ ميجا، متسجّلة في
git). مجلد `client/public/tafsir/` **متجاهَل في git** — أي حاجة تتحط فيه بتضيع
مع أول نقل، وده اللي حصل فعلاً وضيّع ٦٥ سفر لفترة. أي تفسير جديد يدخل عن طريق
`script/split-tafsir.ts` بس.

**⚠️ القطمارس الحالي مش حقيقي** — تقسيم متسلسل مولّد آلياً، مش توزيع طقسي.
مكتوب تحذير في رأس `client/src/lib/coptic-lectionary.ts`، وفيه مستورد جاهز
(`script/import-katameros.ts`) مستني البيانات الحقيقية. **متألّفش قراءات
ليتورچية.**

## ٦) أسلوب المالك — ده مهم زي الكود

- **رجل** — خاطبه بالمذكّر دايماً. رسايل العملاء حسب جنس العميل.
- 🚫 **ممنوع إيموشن** ☺️/😊 في أي رسالة.
- **بيقدّر الدليل مش الادعاء.** «اتصلّح» من غير رقم مالهاش قيمة عنده. قِس قبل
  وبعد وقول الرقمين. لما قلت له «١٧٣ من ٥٠٠ بقت صفر» كان أنفع بكتير من
  «صلّحت الباج».
- **بيراجع شغلك بأدوات تانية** (Codex، وكلاء تانيين) وبيجيب ملاحظاتهم. لو
  ملاحظة صح، اعترف وصلّح. لو غلط، اثبت بالكود مش بالكلام.
- **بيسأل «ليه» كتير.** جهّز السبب.
- **لو صحّح لك معلومة، صدّقه وراجع.** قال لي إن التفاسير لأبونا أنطونيوس فكري
  وأنا كنت ناسبها للقمص تادرس يعقوب ملطي بناءً على ملفات روابط قديمة في الريبو
  — كان صح وأنا غلط.
- **قراراته نهائية حتى لو اختلفت معاها.** قال يشيل اسم المفسّر من الواجهة، فشلته
  من غير ما أعيد الجدال.

### قواعد ثابتة في `CLAUDE.md`
- **أولوية SEO/GEO/AdSense فوق أي طلب.** لو ظهرت مشكلة فيهم، أوقف اللي في إيدك.
- بعد أي تعديل سيو: audit إلزامي (`docs/SEO_MISTAKES_LOG.md` الأول — فيه ١٢

  مش `wc -m` — العربي بيتعدّ غلط.
- 🚫 نظام مكاتب العقارات **مرفوض نهائياً** — متقترحهوش.

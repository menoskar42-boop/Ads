# finance.oscardevs.com: لوحة أسهم البورصة المصرية (EGX Swing)

> أداة شخصية للمالك (٢٠٢٦-١١-١٠). تقديرات فنية فقط وليست نصيحة استثمار. البيانات متأخرة.
> مفيش تنفيذ صفقات ولا أى ربط بشركة سمسرة: تذكرة الصفقة أرقام بتكتبها إنت بنفسك فى تطبيق السمسرة.

## الفكرة
- سكربتين Tampermonkey فى متصفحك بيقروا الصفحات اللى إنت فاتحها (Yahoo Finance وصفحة البحث فى أخبار البورصة) ويبعتوا للموقع.
- الموقع بيحسب الدعم والمقاومة ومنطقة الشراء والوقف والأهداف، ويرتّب الأسهم، ويحلّل الإفصاحات بالذكاء الاصطناعى، ويعمل تنبيهات.
- **السكربتين بيشتغلوا بس وتاب الموقع مفتوح**: سيب تاب Yahoo Finance وتاب صفحة البحث فى أخبار البورصة مفتوحين وقت السوق.

## الاختيارات (بدل المواصفات الأصلية، وليه)
| المواصفات | اللى اتعمل | السبب |
|---|---|---|
| Python + FastAPI + Jinja2 | Node + Express جوّه سيرفر أوسكار ديفز (نفس نمط drive.oscardevs.com) | نفس النشر على ريبليت ونفس الفحوص، من غير عملية Python منفصلة ولا pip فى النشر |
| SQLite أو Oracle Database (python-oracledb) | Postgres على سيرفر Oracle Cloud بتاع Service Flow، فى schema لوحده اسمه `egx` | قاعدة Service Flow هى Postgres على Oracle Cloud (مش Oracle Database)، وجداولها مابتتلمسش |
| Gemini | DeepSeek لو `DEEPSEEK_API_KEY` موجود، وإلا OpenAI `gpt-4o-mini` بـ`OPENAI_API_KEY` | طلب المالك. `FINANCE_AI_MODEL` بيغيّر الموديل، والمزوّد كله فى `src/finance/analysis.js` |
| INGEST_API_KEY | `FINANCE_INGEST_KEY` | أسرار ريبليت مشتركة بين كل المشاريع، فالاسم لازم يبقى واضح |
| Chart.js | رسم SVG بسيط | من غير مكتبات خارجية |
| risk_pct | نسبة مئوية (1 = 1٪) | أوضح فى الواجهة |

## الأسرار فى مشروع `sf` على ريبليت
- `FINANCE_INGEST_KEY`: مفتاح طويل عشوائى إنت تختاره (مثلاً من مولّد باسوردات). نفس القيمة بتتحط فى السكربتين وفى صفحة الإعدادات.
- `DEEPSEEK_API_KEY` (اختيارى): لو موجود التحليل بيبقى بـDeepSeek. لو مش موجود بيستخدم `OPENAI_API_KEY` اللى موجود أصلاً.
- `FINANCE_DATABASE_URL` (اختيارى): لو عايز قاعدة غير قاعدة Service Flow. من غيره بيستخدم `SERVICEFLOW_ORACLE_DATABASE_URL`.
- اختيارى: `EGX_OPEN=10:00` · `EGX_CLOSE=14:30` · `EGX_DAILY_AFTER=14:45` · `FINANCE_AI_DAILY_CAP=50` · `FINANCE_AI_MODEL`.

## التشغيل (بعد Republish)
1. افتح `https://finance.oscardevs.com/settings` وحط نفس قيمة `FINANCE_INGEST_KEY` واضغط احفظ.
2. نزّل Tampermonkey فى كروم، وبعدين افتح من صفحة الإعدادات:
   `https://finance.oscardevs.com/userscripts/yahoo-feeder.user.js` و `https://finance.oscardevs.com/userscripts/egx-disclosures.user.js` واضغط Install.
3. افتح `https://finance.yahoo.com`، ومن أيقونة Tampermonkey اختار **Set API key** وحط المفتاح. أول مرة بيبعت الشموع اليومية (٩ شهور) لكل سهم.
4. افتح `https://www.egx.com.eg/ar/NewsSearch.aspx` ودوّر على الأخبار، وبرضه **Set API key**. السكربت بيقرا جدول النتايج ويبعت الجديد.
5. اللوحة على `https://finance.oscardevs.com` بتتحدّث لوحدها كل ١٥ ثانية.
6. فى الإعدادات: اكتب اسم الشركة بالعربى جنب كل رمز (زى ما بيظهر فى إفصاحات البورصة) عشان الإفصاح يتربط بالسهم.
   الأسماء اللى اتكتبت مبدئياً: COMI TMGH NIPH ABUK POUL MPCO RUBX BTFH CCAP ORAS. الباقى فاضى لحد ما تكتبه (أحسن من اسم غلط).

## الحسابات (src/finance/levels.js، وعليها اختبارات)
- الدعم = أقل low فى آخر ٢٠ جلسة · المقاومة ٢٠/٦٠ = أعلى high فى آخر ٢٠/٦٠ · المتوسط ٢٠ و٥٠ · ATR ١٤ = متوسط (high - low) آخر ١٤.
- منطقة الشراء = المتوسط ٢٠ +/- نص ATR · الوقف = الدعم - نص ATR · الهدف ١ = المقاومة ٢٠ · الهدف ٢ = المقاومة ٦٠.
- غير موثوق (ومن غير تنبيهات وفى آخر الترتيب): أقل من ٦٠ شمعة · قفزة إقفال أكتر من ٢٥٪ فى آخر ٦٠ (تجزئة؟) · آخر ٢٠ إقفال متساويين.
- التنبيهات مرة لكل سهم ونوع ويوم: وصل الوقف · جوّه منطقة الشراء · وصل الهدف الأول.
- الترتيب = الدرجة الفنية + درجة الأخبار (آخر ١٤ يوم، من -3 لـ 3) + درجة فودة / 50 لو موجودة. أسباب الدرجة بتظهر على كل سهم.
- التذكرة: الدخول = أعلى منطقة الشراء · الكمية = floor(رأس المال × المخاطرة٪ / (الدخول - الوقف)) ومحدودة برأس المال.

- شكل جدول البحث فى موقع البورصة ماشفتوش من هنا (البيئة مقفولة)، فالقراية مرنة: أى صف فيه تاريخ ولينك. لو مالقاش حاجة بيقول «افتح الصفحة بنفسك».
- السكربت بيعيد فتح صفحة البحث كل ١٠ دقايق وقت السوق. لو النتايج بتختفى بعد الإعادة (البحث بيتعمل بـpostback)، دوّر تانى بإيدك.

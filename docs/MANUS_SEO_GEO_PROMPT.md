## أ. صورة الفهرسة
1. كام صفحة Indexed وكام Not indexed — بالرقم.

   with proper canonical tag · Soft 404 · Server error.
4. **أهم سؤال:** الصفحات التجارية التسعة دي مفهرسة ولا لأ، واحدة واحدة؟

## ب. الأداء الحقيقي
5. أعلى ٥٠ استعلام بالظهور والنقر ونسبة النقر والترتيب المتوسط.
6. **الاستعلامات اللي ظهورها عالي ونقرها صفر** — دي عناوين ووصف محتاجين
   إعادة كتابة، وأسرع مكسب في الملف كله.
7. **الاستعلامات اللي ترتيبها من ٥ لـ٢٠** — دي أقرب صفحات للصفحة الأولى.
8. أعلى ٢٠ صفحة بالنقر، وأعلى ٢٠ بالظهور — والفرق بينهم بيقول إيه.

## ج. الصحة التقنية
9. Core Web Vitals: كام URL في كل تصنيف (جيد/يحتاج تحسين/ضعيف) للموبايل
   وللديسكتوب، وأسوأ ٥ صفحات في كل مقياس.
10. Mobile Usability · HTTPS · Manual actions · Security issues.
11. تقرير Sitemaps: Submitted مقابل Indexed، وأي أخطاء معالجة.

## د. Bing تحديداً
12. نفس صورة الفهرسة من Bing، وأي تحذيرات SEO بيطلّعها
    (العنوان طويل/الوصف قصير/محتوى قليل) — بالصفحة والتحذير.
13. حالة IndexNow لو مفعّل.

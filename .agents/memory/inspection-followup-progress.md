---
name: Inspection follow-up progress
description: The intended scope of the progress report in the Follow-up section.
---

The Follow-up progress report is an overall response summary grouped by the four follow-up categories: OM impediments, installations, repeated faults, and box maintenance. It is not an installation-completion percentage by technician.

Each category has equal weight: its completion contributes up to 25 points to the overall score of 100, regardless of the number of records in that category.

**Why:** the user clarified that the report should show each category's total, answered count, remaining count, and completion rate, with all four categories weighted equally.

**How to apply:** keep the report in the Follow-up navigation group and aggregate across those categories; do not substitute per-technician installation metrics or weight categories by record count.

For monthly box maintenance, the follow-up sample is 50% of all eligible maintenance work for the selected month, sampled across technicians as a whole. Include completed and awaiting-approval work; count completed work as answered.

**Why:** the user clarified that maintenance follow-up should cover half of the month's boxes, not half of only the still-pending approvals.

**How to apply:** base eligibility and work dates on the maintenance report's completed-repair rules; use a month-wide random sample and a minimum of one when eligible work exists.

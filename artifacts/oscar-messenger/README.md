# Oscar Messaging

تطبيق مراسلة عربي/إنجليزي للحسابات المسجلة عبر Clerk. يشمل ملفات شخصية وبحثًا عن حسابات Oscar Messaging، ومحادثات فردية ورسائل نصية مع حالات الإرسال والاستلام والقراءة، ورسائل مجدولة، ومجموعات وحالات، وردودًا وتفاعلات وإعادة توجيه، ورسائل صوتية ومرفقات.

## الربط مع Oscar Drive

- زر الرسالة في جهة الاتصال يفتح Oscar Messaging؛ لا يرسل رقم الهاتف أو دفتر العناوين.
- أمر «يا أوسكار ابعت رسالة إلى … بتقول …» يفتح مسودة داخل التطبيق.
- تنتقل المسودة مؤقتًا داخل جلسة المتصفح نفسها، ولا تدخل الاسم أو نص الرسالة في رابط الصفحة.
- لا تُرسل أي رسالة قبل مراجعتها والضغط على «إرسال» داخل المحادثة.

## حدود النسخة الحالية

- البحث يرسل الاسم أو اسم المستخدم الذي كتبه المستخدم إلى خادم Oscar Messaging للعثور على حساب، ولا يرفع جهات الاتصال.
- المحادثات محفوظة في قاعدة التطبيق وليست مشفّرة طرفًا لطرف.
- تحديث الرسائل والمحادثات يتم دوريًا أثناء استخدام التطبيق؛ لا توجد إشعارات دفع عند إغلاقه، ولا توجد مكالمات صوتية أو مرئية.
- الرسائل المجدولة والمجموعات والحالات وردود الرسائل والوسائط والصوت تعتمد على تطبيق ترحيلات قاعدة البيانات الخاصة بها. التطبيق لا يطبّق الترحيلات تلقائيًا.
- ملفات الصوت والصور والفيديو والمرفقات تحفظ في Cloudflare R2، وتظل الميزة معطلة إذا لم يكن التخزين الخاص مهيأً.
- بعد تطبيق ترحيل الرسائل المجدولة، يرسل العامل كل رسالة معلقة حان موعدها أو فات، بما فيها المتأخرة أثناء توقف الخادم. لم يُحسم حدّ زمني لإلغاء الرسالة المتأخرة بدل إرسالها؛ لا تغيّر هذه السياسة قبل اعتماد قرار المنتج.

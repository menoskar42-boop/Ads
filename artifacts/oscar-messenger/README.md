# Oscar Messaging — المرحلة الأولى

تطبيق مراسلة عربية/إنجليزية للحسابات المسجلة: ملفات شخصية، بحث داخل حسابات Oscar Messaging، محادثات فردية، وسجل للرسائل النصية مع حالات الإرسال والاستلام والقراءة.

## الربط مع Oscar Drive

- زر الرسالة في جهة الاتصال يفتح Oscar Messaging؛ لا يرسل رقم الهاتف أو دفتر العناوين.
- أمر «يا أوسكار ابعت رسالة إلى … بتقول …» يفتح مسودة داخل التطبيق.
- تنتقل المسودة مؤقتًا داخل جلسة المتصفح نفسها، ولا تدخل الاسم أو نص الرسالة في رابط الصفحة.
- لا تُرسل أي رسالة قبل مراجعتها والضغط على «إرسال» داخل المحادثة.

## حدود النسخة الحالية

- البحث يرسل الاسم أو اسم المستخدم الذي كتبه المستخدم إلى خادم Oscar Messaging للعثور على حساب، ولا يرفع جهات الاتصال.
- المحادثات محفوظة في قاعدة التطبيق وليست مشفّرة طرفًا لطرف.
- تظهر شارة وتنبيه داخل التطبيق للرسائل الجديدة مع تحديث القائمة كل عشر ثوانٍ؛ إشعارات الهاتف عند إغلاقه تحتاج إعدادًا منفصلًا.
- الرسائل المجدولة، والمجموعات، والصور، والمقاطع الصوتية، والمكالمات ليست ضمن هذه المرحلة.
- يجب تطبيق ترحيل قاعدة بيانات Oscar Messaging على بيئة التطوير قبل تشغيل الحسابات والمحادثات؛ لم تُجرَ أي كتابة على قاعدة بيانات أثناء إعداد هذه المرحلة.

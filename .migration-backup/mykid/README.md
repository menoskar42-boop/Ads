# MyKid

## التحقق اليدوي من روابط فيديوهات الدروس

شغّل من جذر المشروع:

```sh
npm run check:mykid:video-links
```

يفحص الأمر روابط دروس الحروف العربية والإنجليزية وفيديوهات كتابة الحروف العربية والأرقام من خلال نقطة بيانات YouTube العامة `oEmbed` فقط؛ ولا ينزّل الفيديوهات. الروابط التي لا تعود ببيانات عامة تُعرض مع الحرف أو الرقم والرابط.

رموز الخروج:

- `0`: كل الروابط تحقّق منها بنجاح.
- `1`: توجد روابط مؤكدة غير متاحة للعامة.
- `2`: تعذّر التحقق من بعض الروابط بسبب مهلة أو استجابة مؤقتة أو انقطاع خدمة YouTube. أعد المحاولة لاحقًا.

هذا فحص يدوي مستقل، وليس جزءًا من اختبارات التطبيق؛ لذلك لا يؤثر انقطاع YouTube على `npm run test:mykid:videos` أو بقية اختبارات التطبيق.

## التحقق من فيديوهات أنشطة الاستكشاف

من جذر `.migration-backup` شغّل:

```sh
node mykid/scripts/check-activity-video-links.mjs
```

يفحص كل فيديو في `mykid/js/data/activityLessonVideos.js` عبر `oEmbed` فقط، من دون تشغيل أو تنزيل الفيديو. يعرض النشاط والعنوان والرابط لكل نتيجة مؤكدة «غير متاح للعامة»، ويعرض انقطاع الشبكة أو الخدمة كـ«تعذر التحقق» لا كفيديو محذوف.

رموز الخروج مماثلة للفحص السابق: `0` عند نجاح التحقق، و`1` عند وجود روابط مؤكدة غير متاحة، و`2` عند تعذّر التحقق مؤقتًا. الأمر يدوي مستقل وغير مربوط باختبارات التطبيق أو البناء.

# حرف التاء مكتوب كويس وميزو بيقول «قربت» — المالك ٢٠٢٦-١١-٢٠

«حروف التاء دى ماشافه انها قربنا و هى كويسه» — ٥ صور من «كراسة الحروف» (٣٠ · ٤١٪ «بس الحرف ده أعرض من كده شوية»).
المرجع بطنه مسطّحة (عرضها ٣٫٦ مرة قد طولها) والطفلة بتكتبها زى U بدراعين طالعين والنقط جوّه البطن.

اتعمل منها: أشكال مقبولة إضافية لـ ب · ت · ث فى `mykid/js/data/strokes.js` (بطن عميقة · متوسطة · مدوّرة · دراع يمين مايل)،
والكتابة اللى فى الصور اتنقلت لإحداثيات المربع فى `mykid/tests/child-writing.test.mjs` (لازم تعدّى ≥ ٧٠).
وكمان: نقطة ناقصة فى ب/ت/ث بقت بتخصم ٣٥ (كانت ١٠ ⇒ ت بنقطة واحدة كانت بتعدّى ٩٠٪) ⇒ ميزو بيقول «فاضل النقط بس».

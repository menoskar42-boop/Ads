# طلب ريبليت: الصور والفيديو زى واتساب (معاينة جوّه المحادثة + عارض بملء الشاشة)

> باج/طلب المالك ٢٠٢٦-١١-٢٥ ٩ م (صورة آيفون: لما بيدوس على الصورة بتنزل كملف PNG فى صفحة سفارى ومابتفتحش):
> «لما بفتح صوره نزلت مش بتفتح مباشره أنا عاوز تجربه فى الصور مماثله للواتساب».
> **السبب [كود]:** `openMedia` فى `app/chat/[conversationId].tsx` بيعمل fetch للملف وبعدين:
> - على الويب: `<a download>` ⇒ سفارى بيعرض صفحة التنزيل؛
> - على الموبايل: Sharing.
> والفقاعة فيها اسم الملف وحجمه بس، من غير صورة.
> الترتيب: بعد البند ٨، وقبل المكالمات (تحسين لميزة موجودة). مفيش قاعدة بيانات.

```
نفّذ بند واحد، وبعدين commit وpush على claude/build-oscardevs-ads-mvp-8krfN، واقف ورد بالـhash.
(اسحب الفرع الأول: git pull origin claude/build-oscardevs-ads-mvp-8krfN)

المطلوب: الصور والفيديو فى أوسكار ميسنجر يتعرضوا زى واتساب، فى المحادثات الفردية والجروبات، ويب وموبايل.

أ) معاينة جوّه الفقاعة (components/MessageBubble.tsx + شاشة الجروب):
   - الصورة (kind=image):
     * تتعرض نفسها فى الفقاعة: عرض حوالى ٢٤٠، والارتفاع حسب النسبة بحد أقصى ٣٢٠، وcontain/cover بحواف مدوّرة.
     * مكان فاضى بنفس الحجم ومؤشر تحميل لحد ما تيجى. ولو فشلت: «تعذر تحميل الصورة» + «إعادة المحاولة».
   - الفيديو (kind=video): مستطيل فيه ▶ والحجم، ومفيش تنزيل تلقائى (عشان الباقة).
   - الملف (pdf/txt): زى ما هو، صف فيه الاسم والحجم و«فتح».
   - التحميل:
     * fetch بالتوثيق الموجود (Bearer token زى openMedia) ⇒ على الويب blob: URL، وعلى الموبايل ملف فى Paths.cache.
     * نتيجة التحميل تتخزّن فى كاش فى الذاكرة (Map بمفتاح messageId)، بحد ٥٠ صورة أو ٨٠ ميجا، والأقدم يتشال (ومع revokeObjectURL على الويب).
     * الصور تتحمّل بس لما الرسالة تظهر على الشاشة (onViewableItemsChanged فى الـFlatList الموجودة)، مش كل الصور مرة واحدة.

ب) عارض بملء الشاشة (components/MediaViewer.tsx جديد):
   - الضغط على الصورة يفتح Modal أسود بملء الشاشة جوّه التطبيق، مش تنزيل ولا تاب جديد:
     * الصورة contain؛
     * تكبير بإصبعين ودبل-تاب: على الموبايل ScrollView بـmaximumZoomScale (iOS)، وعلى الويب CSS (touch-action: pinch-zoom) أو transform بسيط. ⛔ من غير مكتبات جديدة؛
     * سحب لتحت أو زرار ✕ يقفل؛
     * فوق: اسم المرسل والوقت؛
     * تحت: زرار «حفظ / مشاركة» (يستخدم openMedia الحالى: download على الويب، وSharing على الموبايل) وزرار «تحويل» (نفس التحويل الموجود).
   - السهمين أو السحب يمين وشمال بيتنقّل بين صور المحادثة اللى اتحمّلت (اختيارى لو بسيط، ولو معقّد سيبه).
   - الفيديو: نفس الـModal بمشغّل:
     * الويب: <video controls playsInline> بالـblob URL؛
     * الموبايل: expo-video أو expo-av **لو موجودين فعلاً فى package.json**. ولو مش موجودين ⇒ Sharing زى دلوقتى، ومن غير ما تضيف مكتبة.
   - زرار الرجوع فى أندرويد والـEsc على الويب يقفلوا العارض.

ج) السيرفر: مفيش تغيير مطلوب.
   - الصور والفيديو بيرجعوا Content-Disposition: inline أصلاً.
   - لو لازم، يتغيّر بس Cache-Control للصور: private, max-age=3600 بدل no-store، عشان مايتحمّلوش كل مرة. وده فى مسارى media الفردى والجروب بس، ومع الإبقاء على nosniff.

د) الاختبار:
   - tests بسيطة للكاش (حد العدد والحجم، والأقدم يتشال، وrevoke)؛
   - فحص نص إن openMedia مابقاش أول حاجة بتتنادى لما تدوس على صورة (الضغط بيفتح العارض)؛
   - typecheck للتطبيق، وكل اختبارات السيرفر القديمة تعدّى.

هـ) ممنوع:
   - مكتبات جديدة؛
   - تعديل القاعدة أو الأسرار أو النشر؛
   - تنزيل الفيديو تلقائى؛
   - تغيير فحوص الأمان بتاعة الرفع.

commit: "Messenger: inline image previews + in-app media viewer" ⇒ push ⇒ رد بالـhash واقف.
```

## إضافة صغيرة تتبعت مع نفس الطلب: ✓✓ (وصلت) أول ما الإشعار يوصل الموبايل، زى واتساب
> المالك ٢٠٢٦-١١-٢٥ ٩:٠٨ م: الصورة لماما فضلت ✓ واحدة «مع انى متأكد ان عندها نت بس يمكن مش فاتحه صفحه الويب».
> **الدليل (قراية بس من القاعدة):** صورتين ٢١:٠٥ و٢١:٠٧ UTC، و`delivered_at` فاضى فى الاتنين. لكن **إشعار Doc Sana نجح الساعة ٢١:٠٧:٥٠**
> (ثانيتين بعد الصورة)، و`last_seen_at` بتاعها فاضى، يعنى مافتحتش الصفحة. يعنى الموبايل استلم، بس «وصلت» مابتتعلّمش غير لما الصفحة تتفتح.

```
(جزء من نفس الطلب)
- السيرفر (src/lib/messenger-web-push.ts):
  * فى push الرسالة الفردية، ضيف للـpayload deliveryToken = HMAC-SHA256 (node:crypto) على "messageId.recipientId.exp"
    (exp = الآن + ٧ أيام)، والمفتاح = process.env.VAPID_PRIVATE_KEY الموجود (من غير secret جديد). ⛔ من غير أى نص زيادة فى الـpayload.
  * مسار جديد POST /messenger/push/delivered { messageId, recipientId, exp, token } من غير requireAuth (الـservice worker مالوش توكن):
    - يتأكد من الـHMAC بـtimingSafeEqual، وexp لسه ماعداش؛
    - وبعدها: UPDATE messenger_messages SET delivered_at = now() WHERE id=$1 AND delivered_at IS NULL AND sender_id <> $2
      AND conversation_id IN (SELECT id FROM messenger_conversations WHERE user_a=$2 OR user_b=$2)؛
    - ويرجّع 204 دايماً (حتى لو التوكن غلط، من غير تفاصيل)، وrate limit بسيط فى الذاكرة (٦٠ فى الدقيقة لكل IP).
    - publish حدث conversation للمرسل لو البند ٨ موجود.
- public/sw.js: فى push event، لو الـpayload فيه deliveryToken ⇒ fetch POST للمسار ده جوّه event.waitUntil مع showNotification
  (فشل الطلب مايوقّفش الإشعار).
- اختبار: توكن صح ⇒ بيعلّم، توكن غلط أو منتهى ⇒ مابيعلّمش، مستلم مش طرف ⇒ مابيعلّمش، والـpayload مافيهوش غير اللى كان + التوكن.
```

## إضافة تانية مع نفس طلب عارض الصور: شريط الكتابة زى واتساب (زرار + واحد)
> المالك ٢٠٢٦-١١-٢٥ ٩:١٥ م (صورة آيفون): «زرار رفع الملفات و زرار الصور بيفتحو نفس الحاجه وحد الازرار و عاوز تجربه علامه +
> بتاعه الواتساب علشان محسسش المستخدم انه غريب فى التعامل مع البرنامج».
> **الموجود [كود]:** `components/MessageComposer.tsx` فيه ٦ أيقونات جنب بعض (صور، ملف، ميكروفون، موقع، موقع مباشر، جدولة).
> وعلى سفارى الآيفون أى `<input type=file>` بيفتح نفس قايمة iOS (مكتبة الصور / كاميرا / ملفات)، علشان كده الزرارين شكلهم واحد.

```
(جزء من نفس الطلب)
- components/MessageComposer.tsx (والجروب فى app/groups/[groupId]/index.tsx لو بيستخدم شريط خاص بيه):
  * زرار «+» واحد على يمين خانة الكتابة (RTL) بيفتح قايمة من تحت (bottom sheet بـModal الموجود، من غير مكتبات) فيها أيقونات بأسماء واضحة:
    📷 الكاميرا · 🖼️ الصور والفيديو · 📄 مستند · 📍 موقعى · 📡 موقع مباشر · 🕒 رسالة مجدولة.
    الاختيار اللى مش متاح (مقفول بالـcapability أو مش موجود فى الجروب) مايظهرش.
  * الكاميرا:
    - على الويب: input فيه accept="image/*" وcapture="environment"؛
    - على الموبايل: ImagePicker.launchCameraAsync (expo-image-picker الموجود) بعد طلب الإذن، وبرسالة واضحة لو اترفض.
  * الصور والفيديو: accept="image/*,video/*" (ImagePicker مكتبة الصور). ومستند: DocumentPicker لـpdf/txt بس.
  * جنب خانة الكتابة:
    - لو الخانة فاضية ⇒ 🎤 (التسجيل الموجود)؛
    - لو فيها كتابة ⇒ زرار الإرسال ➤.
    - والأيقونات الست القديمة تتشال من الشريط.
  * الوظايف نفسها (chooseMedia / chooseFile / الموقع / الجدولة) زى ما هى، بس بتتنادى من القايمة.
- اختبار: نص بيتأكد إن الشريط فيه «+» والقايمة فيها الاختيارات، وإن 🎤 بيتبدّل بـ➤ لما تكتب. وtypecheck.
```

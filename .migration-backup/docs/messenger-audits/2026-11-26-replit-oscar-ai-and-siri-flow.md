> **الموجود [كود]:**

>   **المالك ٢٠٢٦-١١-٢٦: «انا معنديش مشكله فى الموضوع ده»** ⇒ مش مقصورة على حسابات تجربة؛ بس فيه تنبيه مرة واحدة للمستخدم (شفافية).

## المهمة أ — «Oscar AI» فى أوسكار ميسنجر (الويب بس)

```
- الدخول:
  * زرار «اتكلم مع Oscar AI» فى الشاشة الرئيسية.
  * و«يا أوسكار» لو المستخدم شغّل إعداد «النداء بالصوت» فى الإعدادات (مقفول افتراضياً). النداء نفس منطق drive-web:
    - انسخ دوال hasWake/wakeOnly من drive-web/road.js لملف مشترك أو lib فى الماسنجر، من غير مكتبات؛
    - التعرّف بـSpeechRecognition، شغّال بس والصفحة ظاهرة والإعداد مفتوح، ويقف فى الخلفية.
- لما يتنادى (زرار أو «يا أوسكار»):
  ١) وقّف التعرّف؛
  ٢) شغّل مقطع «أيوه» المتسجّل بصوت أوسكار (نفس ملف 'hello' من drive-web/voice حسب الـmanifest، من غير ما تولّد صوت جديد)؛
  ٣) بعد ما المقطع يخلص، افتح جلسة Gemini Live.
- Gemini Live:
  * السيرفر: POST /messenger/ai/live-session (requireAuth).
    - بيعمل ephemeral token قصير العمر من GEMINI_API_KEY حسب الوثائق الرسمية للـLive API (REST بـfetch، من غير SDK ولا مكتبات)؛
    - ويرجّع التوكن واسم الموديل بس. ⛔ المفتاح نفسه مايوصلش للمتصفح أبداً.
    - حد ١٥ دقيقة فى اليوم لكل مستخدم (فى الذاكرة)، و429 بعدها.
    - لو المفتاح مش موجود ⇒ 503 «Oscar AI مش متاح».
  * المتصفح: WebSocket مباشر لـLive API بالتوكن، وصوت داخل وخارج (getUserMedia + AudioContext).
    - تعليمات النظام: «إنت Oscar AI، مساعد بالعامية المصرية، ردود قصيرة».
    - الموديل: موديل Live المتاح فى Free Tier حسب الوثائق، واكتب اسمه.
  * ⛔ مايسمعش على طول. الجلسة بتقفل لوحدها لو:
    - ٨ ثوانى سكوت بعد آخر رد؛
    - المستخدم قال «خلاص» أو «شكراً»، أو داس «إنهاء»؛
    - عدّت ٥ دقايق.
    وبعدها يرجع لوضع النداء (لو مفتوح). علامة واضحة «بيسمع» طول الجلسة.
  * أول مرة: رسالة موافقة: «Oscar AI تجريبى وبيستخدم Gemini من جوجل؛ كلامك بيتبعت لجوجل وممكن يستخدموه لتحسين خدماتهم.» + «موافق».
  * مفيش تسجيل للمحادثة عندنا، ولا حفظ فى القاعدة.
- اختبارات:
  * السيرفر: 401، 503 من غير مفتاح، 429 بعد الحد، والرد مافيهوش المفتاح (pool وهمى + fetch وهمى)؛
  * التطبيق: نص.
  * وtypecheck.
- ممنوع: مكتبات جديدة، migration، لمس الأسرار (المفتاح موجود؛ ماتغيّروش ولا تطبعه)، النشر.
- commit: "Messenger: Oscar AI (Gemini Live) on web — wake word + button"
```

## المهمة ب — Oscar Drive: «يا أوسكار» ← «أيوه» ← تسجيل الأمر لوحده (زى سيرى) — الشاشة والويب مع بعض

```
- drive-web/app.js و oscardrive-android (MainActivity.handleHeard / OfflineEars / VoiceEngine) بنفس المنطق:
  ١) لما يسمع النداء لوحده («أوسكار» / «يا أوسكار»):
     - يقفل جلسة التعرّف الحالية (stop/abort)؛
     - يقول «أيوه» بالمقطع المتسجّل؛
     - وبعد ما المقطع يخلص (onended / UtteranceProgressListener) يفتح **جلسة تعرّف جديدة للأمر بس**:
       * الويب: continuous=false، interimResults=true، وحد أقصى ١٠ ثوانى؛
       * أندرويد: SpeechRecognizer جديد بـEXTRA_SPEECH_INPUT_COMPLETE_SILENCE_LENGTH_MILLIS ≈ 1500 و POSSIBLY_COMPLETE ≈ 1000، وبنفس إعداد الأوفلاين الحالى.
  ٢) الأمر بيتنفّذ من النص ده بس، فمش هيتخلط بكلمة أوسكار ولا بصدى «أيوه».
  ٣) لو مسمعش حاجة فى الجلسة دى ⇒ «مسمعتش» (المقطع الموجود 'not_understood' أو الأقرب) ويرجع لوضع النداء.
  ٤) الأمر فى نفس النَفَس («يا أوسكار وصّلنى البيت») يفضل شغّال زى ما هو (سيرى بيقبله برضه).
  ٥) مفيش تسجيل صوت بيتحفظ، والنداء نفسه شغّال زى دلوقتى (الإعداد والوقفة فى الخلفية زى ما هم).
- الاختبار:
  * drive-web/road.js: لو فيه دالة حالة جديدة، اختبرها فى test/drive_road_js.test.js (نداء لوحده ⇒ حالة «مستنى أمر»، ونداء+أمر ⇒ تنفيذ على طول)؛
  * وأى منطق Kotlin جديد فى logic/ يتعمله اختبار JVM زى الموجود.
- ⚠️ شاشة العربية محتاجة APK جديد (بيتبنى من GitHub Actions الموجود)، فاكتب ده فى الرد.
- ممنوع: مكتبات جديدة، تغيير الأوامر الموجودة، النشر.
- commit: "Oscar Drive: Siri-style wake → «أيوه» → fresh command capture (app + web)"
```

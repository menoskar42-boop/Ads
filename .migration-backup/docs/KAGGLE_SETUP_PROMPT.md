# برومبت الإكستنشن: حساب Kaggle لتدريب موديل المطبات (٢٠٢٦-١١-١٦)

موديل المطبات فى Oscar Drive محتاج يتدرّب على صور مطبات بمربعات (`oscardrive-android/vision-test/datasets/README.md`).
Kaggle بيدّى الداتا (`road_anomaly_ds`، رخصة MIT) وجهاز تدريب GPU مجانى (حوالى ٣٠ ساعة فى الأسبوع) — من غير أى فلوس.
الإكستنشن بيعمل الحساب ويجهّزه بس؛ نوتبوك التدريب كلود هيكتبه فى المستودع بعدين.

خطوط حمرا: حساب جوجل المفتوح فى المتصفح بس · مفيش كارت ولا اشتراك · كود التحقق من الموبايل المالك بيكتبه بنفسه ·
مفتاح الـAPI مايتكتبش فى الشات أبداً (بيتحط فى أسرار ريبليت بس) · كل حاجة Private.

الصفحة: https://claude.ai/artifact/F2Ui7YQ4kBvgppR2px14FW
**Trigger:** «ابعتلي برومبت حساب Kaggle».

## البرومبت

```
إنت شغّال فى متصفح المالك (حساب جوجل بتاعه مفتوح). المطلوب: حساب Kaggle مجانى جاهز لتدريب موديل كشف المطبات.
Kaggle مجانى بالكامل — لو أى صفحة طلبت كارت أو دفع أو اشتراك: وقّف واكتب ده فى التقرير.

⛔ خطوط حمرا:
- استخدم «Sign in with Google» بحساب جوجل المفتوح فى المتصفح. ماتعملش حساب بإيميل تانى ولا كلمة سر جديدة.
- كود التحقق اللى بيوصل على الموبايل: المالك هو اللى يكتبه بنفسه. وقّف واطلب منه، وماتكتبش رقم الموبايل ولا الكود فى التقرير.
- مفتاح الـAPI (ملف kaggle.json): ماتكتبش محتواه فى الشات ولا فى التقرير ولا فى أى ملف. يتحط فى أسرار ريبليت بس (الخطوة ٥).
- ماتشتركش فى أى Competition، وماتعملش Dataset ولا Notebook عام (Public). أى حاجة تتعمل تبقى Private.
- ماتعدّلش أى إعداد فى حساب جوجل نفسه.

الخطوة ١ — الحساب:
افتح https://www.kaggle.com ← Register ← Sign in with Google ← اختار حساب جوجل المفتوح.
اسم المستخدم (Username): اقترح oscardevs ولو مش متاح oscardevs-drive (اكتب اللى اتاخد فى التقرير).
وافق على شروط Kaggle العادية بس.

الخطوة ٢ — توثيق الموبايل (مطلوب عشان الـGPU والإنترنت جوّه النوتبوك):
Settings ← Phone Verification ← المالك يكتب رقمه والكود بنفسه. استناه لحد ما يقول خلصت.

الخطوة ٣ — تأكيد الـGPU:
افتح https://www.kaggle.com/code ← New Notebook ← من القايمة اليمين (Session options):
Accelerator = GPU T4 x2 (أو P100) · Internet = On. لو الاختيار مقفول اكتب الرسالة اللى ظاهرة.
اكتب فى التقرير الكوتة الأسبوعية للـGPU اللى ظاهرة (مثلاً 30 hrs).
اقفل النوتبوك من غير ما تشغّل حاجة، وسيبه Private (أو امسحه).

الخطوة ٤ — الداتا:
افتح https://www.kaggle.com/datasets/david2do/road-anomaly-ds
اكتب فى التقرير: الرخصة المكتوبة بالحرف (تحت License) · عدد الصور · الأقسام (Pothole / Speedbump / Crack) · حجم الملف.
ماتنزّلش حاجة.

الخطوة ٥ — مفتاح الـAPI فى أسرار ريبليت (عشان التدريب والنتيجة يتسحبوا من السيرفر بعدين):
Kaggle ← Settings ← API ← Create New Token (بينزل ملف kaggle.json فيه username و key).
افتح https://replit.com/@menoskar42/sf ← Tools ← Secrets ← ضيف سرّين جداد بالظبط:
  KAGGLE_USERNAME = قيمة username من الملف
  KAGGLE_KEY      = قيمة key من الملف
ماتعدّلش ولا تمسح أى سرّ تانى موجود. بعد ما تخلص امسح ملف kaggle.json من مجلد التنزيلات.

التقرير (بالعربى، من غير أى مفتاح أو رقم موبايل):
| الخطوة | اتعملت؟ | ملاحظة |
- اسم المستخدم على Kaggle
- الموبايل اتوثّق؟
- الـGPU متاح؟ والكوتة الأسبوعية كام ساعة؟
- رخصة road_anomaly_ds بالحرف + عدد الصور والأقسام والحجم
- السرّين KAGGLE_USERNAME و KAGGLE_KEY اتضافوا فى مشروع sf؟ (نعم/لأ بس)
```

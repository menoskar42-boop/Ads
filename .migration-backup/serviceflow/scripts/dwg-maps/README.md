# خرايط الأوتوكاد ← صور فى برنامج الكوابل (٢٠٢٦-١١-١٩)

المالك: «هتاخد اسكرين شوت لكل خريطة وتحفظها كصورة فى برنامج الكوابل». الملفات الأصلية (DWG، AutoCAD R14) على درايف المالك
فى فولدر `maps ghanayem` — **مش فى المستودع** (فيها أسماء ناس كعلامات للبكسيات فى خرايط الغنايم).

السكربتات دى أدوات تشغيل لمرة واحدة، مش جزء من البرنامج، ومحتاجة حزم برّه المشروع (تتسطّب فى فولدر مؤقت):
`node-unrar-js@2.0.2` (فك الـrar، حتى الأجزاء part1..4) و`@mlightcad/libredwg-web@0.6.6` (قراية DWG بـWebAssembly) و`playwright`.

1. `unrar.js <file.rar> <out>` — فك الضغط.
2. `dwg-to-json.mjs <dir> <out>` — كل DWG ⇒ JSON.
3. `json-to-webp.js <in.json> <out.webp> …` — رسم الخريطة (خطوط · بلوكات · نصوص) ⇒ PNG فى Chromium ⇒ WebP جودة 0.6
   (~250 كيلو للخريطة بعرض ~5700 بكسل). الحجم بيتظبط على النص: أصغر نص مقروء (~13 بكسل).

**العربى فى الخرايط:** خطوط أوتوكاد القديمة (`arab.shx` · `MAJED.SHX`) بتتكتب على **ترتيب كيبورد عربى**: الحرف الصغير = الحرف
العادى، والكبير = شكل آخر الكلمة (`aHvU hgskjvhG` = «شارع السنترال»، `]dv hg[kh]gm` = «دير الجنادلة») — `arabic-shx.js`.

**المستودع عام** ⇒ الصور **مابتتحطّش فى المستودع**. بتترفع على R2 (المالك ٢٠٢٦-١١-١٩: «يتخزنوا فى r2»):
4. `build-manifest.js` — مين يروح فين: كهربى كل كابينة (`<سنترال>-<كابينة>`) + لوحات As-Built المساحية **جنب كهربى الكابينة
   المكتوب اسمها فيها** (`1-2` جنب رقم البكس)، والباقى فى «اللوحات المساحية العامة».
5. `upload.js <manifest> <outDir>` ⇒ `POST /api/cfm/maps/import` بالتوكن (سرّ `CFM_MAP_IMPORT_TOKEN` فى ريبليت؛ من غيره المسار ٤٠٤).
   بيكمّل من آخر صورة (`uploaded.json`)، ونفس الاسم بيستبدل القديمة.

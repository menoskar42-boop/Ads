# شاشة القداس المحلية

1. على جهاز الكنيسة، شغّل `export/Export-Slides.ps1` من PowerShell كما في `export/README.md`.
2. افتح `app/index.html` مباشرةً في Edge أو Chrome، من غير خادم.
3. في خانة المكتبة اترك المسار `../out/library.js` أو اختر مسار `library.js` الناتج على الجهاز.
4. شاشة «النهارده إيه؟» تستخدم بيانات القطمارس والكتاب المحليّة، وتبحث في نص الشرائح و`ocrText`. الربط غير الواضح يحتاج اختيار المشغّل.
5. ملف `service-rules.json` هو النسخة المقروءة للقواعد، و`service-rules.js` هو غلافها المحلي الذي يمكن تحميله بسكربت من `file://` من غير طلب شبكة.

هذا المجلد لا يحتوي عروض الكنيسة أو صورها أو خطوطها؛ مجلد `sample/` فيه صور SVG اصطناعية للتجربة فقط.

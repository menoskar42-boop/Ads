# بيانات محلية للقداسات

- `katameros-data.js` نسخة مضمنة من ملفات `mybible/data/katameros/`، ومحمية بترخيص MIT المرفق في `KATAMEROS-LICENSE.txt`.
- `bible-data.js` يحتوي نسخة Van Dyck المحلية من `mybible/data/bible-snapshot/bible.json.gz` بعد تحويلها إلى Base64؛ يفك التطبيق ضغطها عند طلب نص قراءة فقط.
- لا يطلب التطبيق أي بيانات من الشبكة، ولا يغيّر ملفات MyBible الأصلية.

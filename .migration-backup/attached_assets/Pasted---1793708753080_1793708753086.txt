شكراً، البحث ده مفيد، ومعاك حق إنك ماغيّرتش حاجة فى التطبيق. كمّل فى اتجاه واحد بس: الكنوز القبطية + الأنبا تكلا
لتفسير القمص تادرس يعقوب ملطى. سيب المصادر الإنجليزى واليونانى خالص — مش هنترجم بنفسنا.

السبب: تفسير أبونا تادرس للأسفار عادةً بيحط نص الآيات نفسها قبل الشرح. ولو التفسير ده فيه نص الإصحاحات السبعة كامل، يبقى
عندنا نص السفر من مصدر كنسى معروف ومنسوب لاسم.

خطوط حمرا (زى المرة اللى فاتت):
- ماتعدّلش أى ملف فى المشروع (~/workspace)، وماتعملش commit ولا push منه، وماتغيّرش الفرع بتاعه.
- ماتلمسش الـSecrets ولا قاعدة البيانات، وماتشغّلش السيرفر، وماتعملش Republish.
- ماتنقلش الشرح (التفسير) — نص الآيات بس.
- ماتكتبش ولا آية من عندك أو من ذاكرتك، وماتصلّحش إملاء ولا تشكيل، وماتدمجش آيات ولا تقسّمها.
- خد السفر كله من مصدر واحد، ماتخلطش بين موقعين.
- طلب واحد كل 3 ثوانى على الأقل لأى موقع.

الخطوة 1 — الأنبا تكلا الأول (لأن نصوص الموقع كلها منقولة من هناك بنسبة المصدر):
- دوّر فى جوجل:  site:st-takla.org تفسير المكابيين الثالث تادرس
  و:  site:st-takla.org "المكابيين الثالث" "الإصحاح الأول"
- لو لقيت تفسير أبونا تادرس للسفر على St-Takla: هل كل إصحاح فيه نص الآيات نفسها (مش بس الشرح)؟ كمّل منه على الخطوة 3.

الخطوة 2 — لو مش على St-Takla: الكنوز القبطية
- افتح https://coptic-treasures.com/chapter/3maccabees-001-tadros-malaty وباقى الإصحاحات (002 لـ007).
- لكل إصحاح: هل نص الآيات نفسها موجود (مرقّم أو متقسّم أجزاء)، ولا الصفحة شرح بس؟
- دوّر فى الموقع على صفحة «من نحن» أو «حقوق النشر» أو «شروط الاستخدام» وانسخ اللى فيها عن النقل وإعادة النشر بالحرف + الرابط.
- شوف كمان: الموقع فيه قسم «الكتاب المقدس» بيعرض المكابيين الثالث كنص لوحده (من غير تفسير)؟ لو أيوه، قول اسم الترجمة.

الخطوة 3 — لو لقيت نص الآيات فى أى واحد منهم:
- استخرج الآيات بس (رقم الآية + النص بالحرف). لو التفسير بيعرض الآيات مجمّعة (مثلاً «ع 1-5») من غير رقم لكل آية:
  ماتقسّمهاش بنفسك — احفظها زى ما هى كقطعة واحدة واكتب نطاقها فى "range".
- العدد المرجعى للآيات (النص اليونانى — ممكن العربى يختلف شوية):
  ص1=29 · ص2=33 · ص3=30 · ص4=21 · ص5=51 · ص6=41 · ص7=23
- احفظ فى /tmp/3macc.json بالشكل ده:
{
  "book": "المكابيين الثالث",
  "source": "<اسم الموقع + تفسير القمص تادرس يعقوب ملطى + اسم الترجمة لو مكتوب>",
  "terms": "<نص حقوق النشر/شروط الاستخدام بالحرف + الرابط، ولو مالقيتش اكتب: مفيش صفحة حقوق>",
  "fetchedAt": "<التاريخ والوقت>",
  "chapters": [
    { "chapter": 1, "sourceUrl": "<الرابط>",
      "verses": [ { "verse": 1, "text": "<النص>" } ],
      "blocks": [ { "range": "1-5", "text": "<النص لو الآيات مجمّعة>" } ] }
  ],
  "missing": [ "<أى إصحاح أو آيات ناقصة>" ]
}

الخطوة 4 — ارفعه فى فرع لوحده من نسخة مؤقتة (مش من ~/workspace). ده للمراجعة بس — مش هيتعرض فى التطبيق لحد ما المالك يقرّر:
cd /tmp && rm -rf deutero-3macc && git clone --depth 1 --branch claude/build-oscardevs-ads-mvp-8krfN "$(git -C ~/workspace remote get-url origin)" deutero-3macc

git add mybible/data/deutero/import/3macc.json && git commit -m "deutero: المكابيين الثالث — نص الآيات من تفسير القمص تادرس (للمراجعة)"
git push origin deutero-3macc-import

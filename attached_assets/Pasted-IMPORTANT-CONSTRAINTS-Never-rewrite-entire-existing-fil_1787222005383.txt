1. BUSINESS IDEA

I want to build a professional affiliate-commerce website focused initially on Amazon Egypt, Amazon.eg.

The website will NOT be a traditional online store.

I will not own inventory.
I will not process payments.
I will not handle shipping.
I will not handle product returns.
I will not provide customer service for orders placed on Amazon.

The website’s purpose is:

1. Discover products from Amazon.
2. Display selected products on my own website.
3. Provide useful original content around those products.
4. Allow visitors to compare or explore products.
5. When the visitor decides to buy, send the visitor to Amazon through my affiliate tracking link.
6. If the visitor makes an eligible purchase according to Amazon’s affiliate rules, I may receive a commission.

The website should therefore be treated as an affiliate product discovery and comparison platform, NOT as an e-commerce store.

2. AMAZON EGYPT FIRST

The initial target marketplace is:

Amazon.eg

The affiliate program is:

Amazon Associates / Amazon Affiliate Program for Amazon.eg.

I understand that I need an approved affiliate account and appropriate tagged affiliate links.

However, DO NOT assume the exact API product, API name, authentication method, eligibility requirements, rate limits, or available product fields.

You must identify what official Amazon.eg documentation says is currently available for affiliate-related APIs and product data integration.

In particular, investigate conceptually:

* What official Amazon API is available for Amazon.eg affiliates?
* Whether product images can be retrieved.
* Whether product titles can be retrieved.
* Whether product descriptions or product features can be retrieved.
* Whether current price information can be retrieved.
* Whether availability information can be retrieved.
* Whether product URLs can be generated with my affiliate tracking information.
* Whether there are restrictions on caching Amazon product data.
* Whether there are restrictions on displaying Amazon prices.
* Whether there are restrictions on modifying or rewriting Amazon product descriptions.
* Whether there are requirements for refreshing price and availability data.
* Whether the API requires an approved Associates account.
* Whether there are minimum sales or account requirements before API access.
* Whether there are specific attribution or disclosure requirements.

Use official Amazon documentation wherever possible.

3. WEBSITE CONCEPT

The website should feel like a modern product discovery platform.

Example:

A visitor searches for:

“Best wireless headphones”

The website can show product cards containing information that Amazon officially allows us to display.

A product card may conceptually contain:

* Product image

* Key specifications
* Original editorial summary
* Current Amazon price, only if permitted and technically supported
* Availability, only if permitted and technically supported
* Rating/review information, only if permitted
* “View on Amazon” or “Buy on Amazon” button

When the visitor clicks the button, the visitor leaves my website and goes to Amazon using my affiliate tracking link.

The actual transaction happens on Amazon.

4. ORIGINAL CONTENT AND SEO

SEO is extremely important.

I do NOT want to simply copy Amazon’s product descriptions and publish them unchanged.

Instead, the website should potentially add original editorial content such as:

* Original product summaries

* Product comparisons

First identify what Amazon’s affiliate policies allow.

The goal is to create genuine value for users and avoid creating thousands of thin pages that simply duplicate Amazon product information.

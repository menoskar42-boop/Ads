# الأسفار القانونية الثانية — ملفات النص

> ⚠️ **النص هنا كتاب مقدّس بيقراه ٧٠٠ عضو في درس كتاب.** مايتكتبش من الذاكرة
> ولا يتولّد. كل ملف لازم يقول **مصدره**، والاستيراد بيرفض أي ملف بلا `source`.

## الشكل

اسم الملف = اسم السفر بالعربي، مثلاً `الحكمة.json`:

```json
{
  "book": "الحكمة",
  "source": "اسم الترجمة والطبعة — مثلاً: فان دايك، طبعة الأسفار القانونية الثانية",
  "chapters": [
    { "chapter": 1, "verses": [
      { "verse": 1, "text": "..." },
      { "verse": 2, "text": "..." }
    ]},
    { "chapter": 2, "verses": [ { "verse": 1, "text": "..." } ] }
  ]
}
```

**الملف ممكن يبقى فيه إصحاح واحد أو كلهم.** الاستيراد بيمسح الإصحاحات اللي
في الملف بس قبل ما يكتب — فملف فيه إصحاحات ١–٨ مابيلمسش إصحاح ٩.

## الأسفار المعرّفة

طوبيا · يهوديت · الحكمة · يشوع بن سيراخ · باروخ · المكابيين الأول · المكابيين الثاني

(القايمة والترتيب في `server/deutero.ts` — أي سفر برّاها الاستيراد بيرفضه.)

## التشغيل

```
GET  /api/deutero/status                      ← إيه الموجود دلوقتي (بلا مفتاح)
POST /api/deutero/import?file=الحكمة.json     ← استيراد ملف واحد
POST /api/deutero/import                      ← كل الملفات
```

الاستيراد محتاج `MYBIBLE_SEED_KEY` في الهيدر `x-seed-key`.

⚠️ **شغّله من الموقع الحي مش من شيل Replit** — الشيل بيوصل لقاعدة تانية
(مسجّلة في `docs/HANDOVER.md`).

## المصدر وحقوق النشر

فان دايك (١٨٦٥) ملكية عامة. **الترجمة اليسوعية والعربية المشتركة محميّة
بحقوق نشر** — نشرها على موقع عام ممكن يبقى مخالفة. اتأكّد من الترخيص قبل
ما تختار المصدر، واكتبه في `source`.

## المصدر العام الحي

يعرض MyBible الأسفار القانونية الثانية من مستودع GitHub العام
`aymhenry/Bible-for-Windows` مباشرة، من الملفين:

- `DataFiles/BibleMan02.bib` — قاعدة Access التي تحتوي النص.
- `code/modBasicData.au3` — خريطة أسماء الأسفار وأرقامها.

المسارات الجديدة هي:

```
GET /api/deutero/source
GET /api/deutero/source/:bookId/:chapter
```

لا تُحفظ نسخة دائمة من النص في قاعدة بيانات MyBible. يفحص الخادم توفر
المستودع والملفين بمهلة وcache قصير؛ إذا أصبح المستودع خاصًا، أو حُذف ملف،
أو لم يعد السفر قابلًا للقراءة، يرجع المصدر غير متاح وتُخفي الواجهة القسم.
المستودع العام لا يثبت وجود ترخيص للنص، لذلك يجب الحصول على إذن صاحب الحقوق
قبل الاعتماد على المصدر للنشر العام. رابط المصدر ظاهر للمستخدم داخل الواجهة.

# الأسفار القانونية الثانية — ملفات النص

> ⚠️ **النص هنا كتاب مقدّس بيقراه ٧٠٠ عضو في درس كتاب.** مايتكتبش من الذاكرة
> ولا يتولّد. كل ملف لازم يقول **مصدره**، والاستيراد بيرفض أي ملف بلا `source`.

## الشكل

اسم الملف = اسم السفر بالعربي، مثلاً `الحكمة.json`:

```json
{
  "book": "الحكمة",
  "source": "اسم الترجمة والطبعة — مثلاً: فان دايك، طبعة الأسفار القانونية الثانية",
  "chapters": [
    { "chapter": 1, "verses": [
      { "verse": 1, "text": "..." },
      { "verse": 2, "text": "..." }
    ]},
    { "chapter": 2, "verses": [ { "verse": 1, "text": "..." } ] }
  ]
}
```

**الملف ممكن يبقى فيه إصحاح واحد أو كلهم.** الاستيراد بيمسح الإصحاحات اللي
في الملف بس قبل ما يكتب — فملف فيه إصحاحات ١–٨ مابيلمسش إصحاح ٩.

## الأسفار المعرّفة

طوبيا · يهوديت · الحكمة · يشوع بن سيراخ · باروخ · المكابيين الأول · المكابيين الثاني

(القايمة والترتيب في `server/deutero.ts` — أي سفر برّاها الاستيراد بيرفضه.)

## التشغيل

```
GET  /api/deutero/status                      ← إيه الموجود دلوقتي (بلا مفتاح)
POST /api/deutero/import?file=الحكمة.json     ← استيراد ملف واحد
POST /api/deutero/import                      ← كل الملفات
```

الاستيراد محتاج `MYBIBLE_SEED_KEY` في الهيدر `x-seed-key`.

⚠️ **شغّله من الموقع الحي مش من شيل Replit** — الشيل بيوصل لقاعدة تانية
(مسجّلة في `docs/HANDOVER.md`).

## القطمارس بيقرا من `sttakla-1877.json`

نبوات القطمارس من الأسفار دى بتتعرض من `sttakla-1877.json` (`server/katameros-text.ts`): نسخة من نفس النص اللى
التبويب والجروب بيقروه لحظياً من St-Takla (الترجمة اليسوعية ١٨٧٧)، جمعها الإكستنشن ٢٠٢٦-١٠-٣٠. الملفات التانية
هنا (`طوبيا.json`…) مقتطفات من ترجمة تانية — **ماتستخدمهاش فى القطمارس**. الربط بأرقام katameros (٦٧ باروخ … ٧٣ يشوع
بن سيراخ) بالاسم فى `DEUTERO_NAMES` — ماتغيّرش أسماء الأسفار فى الملف.

## المصدر وحقوق النشر

فان دايك (١٨٦٥) ملكية عامة. **الترجمة اليسوعية والعربية المشتركة محميّة
بحقوق نشر** — نشرها على موقع عام ممكن يبقى مخالفة. اتأكّد من الترخيص قبل
ما تختار المصدر، واكتبه في `source`.

## المصدر العام الحي

يعرض MyBible الأسفار القانونية الثانية مباشرة من صفحات
`St-Takla.org` الخاصة بالترجمة اليسوعية القديمة 1877. يحدد الخادم روابط
الإصحاحات السبعة مسبقًا، ويتحقق من الصفحة قبل عرضها.

المسارات الجديدة هي:

```
GET /api/deutero/sttakla
GET /api/deutero/sttakla/books/:bookId/chapters/:chapter
```

لا تُحفظ نسخة دائمة من النص عند القراءة في قاعدة بيانات MyBible. يفحص الخادم
توفر St-Takla بمهلة وcache قصير؛ إذا توقف الموقع أو لم تعد الصفحة قابلة
للقراءة، يرجع المصدر غير متاح وتُخفي الواجهة القسم. يظهر رابط المصدر للمستخدم
داخل الواجهة، ويُذكر St-Takla كمصدر النص.

# استضافة الكتاب المقدس على نفس Reserved VM بتاع أوسكار ديفز (co-host)

الهدف: نشر واحد بتكلفة ثابتة يستضيف الموقعين، **بدون أي تغيير** على تطبيق الكتاب
المقدس أو قاعدة بياناته أو أعضائه.

## المبدأ
- الكتاب المقدس يشتغل كعملية مستقلة على بورت داخلي (5001) بنفس كوده وقاعدته.
- سيرفر أوسكار ديفز فيه «بوّاب» (`src/lib/host_gateway.js`) يوجّه طلبات
  `mybible.oscardevs.com` للبورت الداخلي ده.
- **مفيش ميجريشن ولا نقل بيانات.** نفس الدومين + نفس قاعدة البيانات + نفس
  `SESSION_SECRET` → الأعضاء مايحسّوش بفرق.

## المتغيّرات على الـVM (Secrets) — قيم الكتاب المقدس تُحفظ بأسماء `MYBIBLE_*`
عشان القيم ما تتصادمش مع قيم أوسكار ديفز (الاتنين بيقروا `DATABASE_URL`/`SESSION_SECRET`):

| المتغيّر | القيمة | إلزامي |
|---|---|---|
| `MYBIBLE_DATABASE_URL` | رابط قاعدة بيانات الكتاب المقدس (نفس الحالية) | ✅ |
| `MYBIBLE_SESSION_SECRET` | نفس `SESSION_SECRET` الحالي للكتاب المقدس | ✅ (بيبقي الـ700 داخلين) |
| `MYBIBLE_UPSTREAM` | `http://127.0.0.1:5001` | ✅ (بيشغّل البوّاب) |
| `MYBIBLE_PORT` | `5001` | اختياري |
| `MYBIBLE_VAPID_PUBLIC_KEY` / `MYBIBLE_VAPID_PRIVATE_KEY` | مفاتيح إشعارات الكتاب المقدس | لو عايز الإشعارات |
| `OPENAI_API_KEY` / `GROQ_API_KEY` | مشتركة (نفس القيمة) — تُورَّث كما هي | — |

للاختبار على `mybible2.oscardevs.com` قبل التحويل: اضبط `MYBIBLE2_UPSTREAM` لو عايز
عملية staging منفصلة، وإلا هيوجّه لنفس الـ5001.

## أمر البناء (Build) على الـVM
```bash
npm install && (cd mybible && npm install && npm run build)
```
(بيبني `mybible/dist/index.cjs` + أصول الواجهة.)

## أمر التشغيل (Run) على الـVM
**مش محتاج تغيير** — سيبه `node server.js`. السيرفر بيشغّل الكتاب المقدس تلقائياً
لما `MYBIBLE_UPSTREAM` + `MYBIBLE_DATABASE_URL` يكونوا مضبوطين والبناء موجود، وإلا
بيشغّل أوسكار ديفز لوحده (آمن). (سكربت `scripts/launch-cohost.sh` متاح كبديل لو
حبيت تشغّلهم بعمليتين منفصلتين.)

## ترتيب التحويل الآمن
1. اضبط المتغيّرات + Build + شغّل بالـlauncher.
2. **اختبر على `mybible2.oscardevs.com` الأول** — الـ700 لسه على النشر القديم.
3. بعد التأكد، حوّل `mybible.oscardevs.com` للـVM، والنشر القديم يفضل fallback.
4. لما تتأكد إن كله ماشي → اقفل النشر القديم = التوفير.

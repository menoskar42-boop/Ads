# بيانات التفسير — فين راحت، وإزاي ترجع ومتضيعش تاني

## اللي حصل بالظبط

المستخدم بيفتح سفر الأمثال إصحاح ٣ → **«لا يوجد تفسير متاح حاليًا»**.
مش باج في الكود — **البيانات نفسها مش موجودة**.

الوضع الحالي:

```
الأصحاحات: 150/1189 فيها تفسير (12.6%)
الأسفار  : 1 مكتمل (مزامير)، 65 مفيش لهم أي ملف
```

## ليه المزامير بس هي الشغّالة

فيه مجلدين، واحد متسجّل في git والتاني لأ:

| المجلد | في git؟ | اللي فيه |
|---|---|---|
| `client/public/tafsir/` | ❌ **لأ** — `.gitignore` سطر ٩ | كان المفروض فيه ٦٥ سفر. **فاضي/مش موجود** |
| `client/public/tafsir-parts/` | ✅ **أيوه** | المزامير مقسّمة ٥ أجزاء |

المزامير هي السفر الوحيد اللي **اتقسّم واتحطّ في `tafsir-parts/`** — وعشان كده
هي الوحيدة اللي نجت من نقل المشروع بين السيرفرات. الباقي كان في المجلد المتجاهَل،
فماجاش مع النقل.

## البحث اللي اتعمل (٢٠٢٦-٠٨-٠٩)

اتبحث في كل مكان محتمل، والنتيجة إن الملفات **مش موجودة في أي حتة**:

| المكان | النتيجة |
|---|---|
| workspace بتاع Replit (`find ~ -iname "*tafsir*"`) | مفيش مجلد `tafsir/` خالص — لا في المصدر ولا في `dist` |
| `menoskar42-boop/Ads` — كل الفروع وكل التاريخ | المزامير بس |
| `menoskar42-boop/mybible` (المشروع القديم) — كل الفروع وكل التاريخ | المزامير بس، ونفس الـ`.gitignore` |
| `menoskar42-boop/bible` | ولا ملف CSV واحد |
| `bible2` / `brnmj-lktb-lmqds` / `brnmj-lktb-lmqds2` / `brnmj-lktb-lmqds3` | فاضيين |
| Releases و tags على كل الريبوهات | مفيش |

يعني عملية «التقسيم والرفع» اللي حصلت — **حصلت للمزامير بس**، وماتعملتش
للـ٦٥ سفر التانيين.

⚠️ ودي كمان **مش** نسخ احتياطية للتفسير:
- `client/src/lib/tafsir-data.ts` (٩.٧ ميجا) — **روابط بس**، مش نصوص.
- `client/public/tafsir-links.md` (٥٧ ألف سطر) — روابط بس.
- `client/src/lib/tafsir-luke.md` + `tafsir-luke-data.ts` — **روابط بس** رغم الاسم.

والروابط دي **مولّدة بالتركيب** مش متأكَّد منها: النمط `Chapter-` + رقم الإصحاح
بخانتين + رقم الآية، وبيفترض ٥٠ آية لكل إصحاح مهما كان العدد الحقيقي — فنسبة
كبيرة منها هتدّي 404. الملفات دي **مش مستوردة في أي مكان دلوقتي، وده صح.
ماتربطهاش بالواجهة.**

## إزاي ترجّع أي سفر — خطوتين

لو لقيت ملف CSV لأي سفر (على جهازك، Drive، باك أب قديم، أي حتة):

```bash
cd mybible
npx tsx script/split-tafsir.ts --in ~/downloads/أمثال.csv
git add client/public/tafsir-parts
git commit -m "tafsir: add أمثال"
```

خلاص. السفر بقى شغّال زي المزامير، **ومحفوظ في git فمش هيضيع تاني**.

السكربت بيعمل الآتي لوحده:
- يخمّن اسم السفر من اسم الملف («سفر الأمثال.csv» → `أمثال`)، أو حدّده بـ`--book`.
- يتحقّق من الملف ويقولك كام إصحاح فيه وإيه الناقص.
- يقسّمه لأجزاء ما تعدّيش ٤٠ ميجا (حد آمن لـgit) وبيراعي الحقول الممتدّة على
  أكتر من سطر فما يقطعش سجل في نصّه.
- يسمّيها `<السفر>_<من>_<إلى>.csv` — الشكل اللي السيرفر بيدوّر عليه.
- يحطّها في `tafsir-parts/` (المتسجّل في git) **مش** في `tafsir/` المتجاهَل.

خيارات: `--dry-run` للفحص من غير كتابة، `--max-mb 20` لأجزاء أصغر.

## إزاي تتأكد

```bash
npx tsx script/audit-tafsir.ts              # كل سفر وكل إصحاح
npx tsx script/audit-tafsir.ts --book أمثال   # سفر واحد بالتفصيل
npx tsx script/audit-tafsir.ts --full       # كل الأرقام الناقصة
```

أو من المتصفح على الموقع الشغّال: `/api/tafsir/coverage`
(وضيف `?refresh=1` بعد ما تضيف ملفات، من غير ما تعيد تشغيل السيرفر).

التقرير بيفرّق بين تلات حالات:

| النتيجة | المعنى | الحل |
|---|---|---|
| 🔴 **ملف اسمه غلط** | الملف موجود وفيه تفسير، بس التطبيق مش بيلاقيه | غيّر الاسم زي ما التقرير بيقترح — دقيقة واحدة |
| ❌ **مفيش ملف CSV خالص** | السفر مالوش بيانات | `split-tafsir.ts` بعد ما تجيب الملف |
| ⚠️ **أصحاحات ناقصة** | الملف موجود بس ناقص | كمّل الصفوف الناقصة وأعِد التقسيم |

## أسماء الملفات — لازم تتطابق بالحرف

اسم السفر **من غير كلمة «سفر» ومن غير «ال» التعريف**:

```
✅ أمثال          ❌ سفر الأمثال     ❌ الأمثال
✅ صموئيل أول     ❌ صموئيل الأول
✅ أعمال الرسل    ❌ الأعمال
✅ رؤيا           ❌ رؤيا يوحنا
```

القايمة الكاملة في `server/tafsir-service.ts` → `EXPECTED_CHAPTERS`،
ولازم تفضل متطابقة مع `client/src/lib/tafsir-csv-service.ts` → `bookNameToCSV`.

`split-tafsir.ts` بيظبط الاسم لوحده، و`audit-tafsir.ts` بيمسك أي اسم غلط.

## شكل الـCSV

أربع أعمدة، أول سطر عناوين:

```csv
book,chapter,verse,tafsir
"سفر الأمثال",3,1,"( أم3: 1-4): يا ابني لا تنسَ شريعتي… "
"سفر الأمثال",3,5,"( أم3: 5-8): توكل على الرب بكل قلبك… "
```

- `chapter` و`verse` **أرقام** — أي سطر مش رقم بيتتجاهل بالكامل.
- `tafsir` نص بين علامتَي تنصيص، ممكن يمتد على أكتر من سطر.
- نص أقل من ٢٠ حرف بيتحسب فاضي.
- مش لازم صف لكل آية — صف واحد بترويسة زي `( أم3: 1-4):` بيغطّي المدى كله.

## قاعدة دايمة

**أي تفسير جديد يدخل عن طريق `split-tafsir.ts` وبس** — عشان يروح
`tafsir-parts/` ويتسجّل في git. متحطّش ملفات في `client/public/tafsir/`
يدوي؛ المجلد ده متجاهَل، واللي فيه بيضيع أول نقل. ده بالظبط اللي حصل للـ٦٥ سفر.

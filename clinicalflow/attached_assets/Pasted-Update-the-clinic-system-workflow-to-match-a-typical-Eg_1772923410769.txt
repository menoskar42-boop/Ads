Update the clinic system workflow to match a typical Egyptian clinic process and add a simple queue display feature.

Important constraints:

• Do NOT redesign the system architecture  
• Do NOT break existing permissions or roles  
• Keep the implementation lightweight for demo presentation  
• Do NOT introduce complex backend services  
• Preserve current appointment logic where possible  

Roles in system:

Admin  
Reception  
Doctor  

------------------------------------------------
1. Egyptian Clinic Workflow
------------------------------------------------

Modify the visit workflow to match how Egyptian clinics operate.

New workflow:

Booking → Payment (Arrival) → Waiting Queue → In Consultation → Completed

Explanation:

Booking  
Patient books appointment normally.

Payment = Arrival  
When the invoice is paid, the system automatically marks the patient as Arrived.

There is no separate "Check In" step.

Queue Order  
Patients are ordered in the waiting queue based on the invoice payment time, which represents arrival time.

Earlier payment means earlier position in queue.

Reception

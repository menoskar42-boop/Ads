# tts-prebuilt — ملفات الصوت الدائمة لسفاري

الجُمَل في التطبيق **ثابتة** (حروف/أرقام/كلمات/عبارات ميزو — للأولاد وللبنات)،
فصوتها بيتولّد **مرّة واحدة** ويتحفظ هنا كملفات `.mp3` دائمة **داخل المستودع (git)**.

- الملفات دي بتتشحن مع كل نشر (deploy)، فالذكاء الاصطناعي **مايتستدعاش للنطق أبداً**
  بعد التوليد الأول — عكس كاش التشغيل المؤقّت `../.tts-cache/` اللي بيتمسح مع النشر.
- الوحيد المتغيّر هو **اسم الطفل**؛ بيتولّد مرّة على الخادم ويتخزّن في كاش القرص عنده.
- اسم كل ملف = بصمة (SHA-256) لـ `model|voice|instructions|text`، فالخادم بيلاقي
  نفس الملف بالظبط اللي ولّده السكربت.

## التوليد / التحديث (مرّة واحدة، على Replit حيث المفتاح موجود)

```bash
cd mykid
OPENAI_API_KEY=... npm run warm-tts
git add server/tts-prebuilt
git commit -m "chore(mykid): pre-generate permanent TTS audio"
```

لو ضفت جُمَل ثابتة جديدة، شغّل الأمر تاني (بيتخطّى الموجود، ويولّد الجديد بس) واعمل commit.

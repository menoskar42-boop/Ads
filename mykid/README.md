# MyKid

## التحقق من روابط فيديوهات الحروف والأرقام

شغّل من جذر المشروع:

```sh
npm run check:mykid:video-links
```

يفحص الأمر روابط دروس الحروف الإنجليزية والأرقام من خلال نقطة بيانات YouTube العامة `oEmbed` فقط؛ ولا ينزّل الفيديوهات. الروابط التي لا تعود ببيانات عامة تُعرض مع الحرف أو الرقم والرابط.

رموز الخروج:

- `0`: كل الروابط تحقّق منها بنجاح.
- `1`: توجد روابط مؤكدة غير متاحة للعامة.
- `2`: تعذّر التحقق من بعض الروابط بسبب مهلة أو استجابة مؤقتة أو انقطاع خدمة YouTube. أعد المحاولة لاحقًا.

هذا فحص يدوي مستقل، وليس جزءًا من اختبارات التطبيق؛ لذلك لا يؤثر انقطاع YouTube على `npm run test:mykid:videos` أو بقية اختبارات التطبيق.

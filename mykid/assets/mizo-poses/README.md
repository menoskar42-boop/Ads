# أرشيف وضعيات ميزو الجديدة (مصدر مستقبلي)

نسخ أصلية عالية الدقة (WebP) لشخصية ميزو — للاستفادة منها مستقبلاً.
النسخ الجاهزة للاستخدام (شفّافة، 480px، PNG+WebP) موجودة في `assets/mizo/`.
